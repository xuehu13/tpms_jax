## 研究主线与本轮问题

长期目标保持：**TPMS 体素/固定背景网格表示 → 可信 JAX-FEM 力学计算 → 构型与参数学习 → 性能驱动的逆向设计 → 独立验证。** 扩散模型是未来方法候选，精度验证是基础；四参数梯度检查不是最终研究目标。

沿用原 M0～M7 的含义：环境、几何、基础力学、TPMS 线弹性、精度验证、非线性、灵敏度、逆向设计。目前主要停留在 **M4 精度验证**，另有部分小网格参数梯度基础。本轮不重新划分整条研究路线。

**本轮只回答：对于当前一个 Gyroid 二值几何，JAX-FEM 固定 HEX8 背景方法能否在横向固定与自由两种线弹性工况下，以可承受成本给出接近独立贴体实体参考的轴向响应？**

这是一项受控基准判断。完成后仍不能推断任意 TPMS、其他相对密度、完整三维均匀化、局部最大应力、非线性压缩或旧壳模型的替代精度。原 M4 所需不同相对密度等扩展尚未完成，是否及如何补充，留到本轮结束后再规划。

## 已有证据与固定定义

- 固定物理几何：一个周期的 Gyroid，实体域 `|G|≤c`，`c=0.541062`，`L=1`。独立二值体积分数估计约 0.350476；不把它写成精确 0.35。阈值 c 不等于常厚壳的厚度。
- 均质基材 `E_s=10`、`ν=0.3`；轴向位移 `u_z=-0.01`，XY 周期、顶底平整加载。横向 fixed 为宏观横向应变固定，free 为平均横向应力松弛；二者分别对照。
- 背景代理采用现有平滑投影，在实际 HEX8 Gauss 点取值，`E=E_min+φ(E_s-E_min)`，即 `p=1`。β 和 `η=E_min/E_s` 是数值近似参数，孔隙不是真实填充材料。
- 旧设置 `β=20、η=1e-3、N=64` 相对 Abaqus 二值 G48 的反力幅值差为 **4.640% / 4.907%（fixed/free）**；N48→N64 变化为 0.303% / 0.322%。
- 候选设置 `β=40、η=1e-4、N=64` 已有 **fixed 差异 1.234%**。它尚缺同设置的 N48 结果与 free 结果。已有 β=40 的 0.374% 网格变化属于 η=1e-3，不能替代此检查。
- 现有独立实体 G32→G48 全局反力变化约 0.60% / 0.61%；G24 同几何 FE 加密及网格重定位已有结果。它们提供参考可信度线索，不构成真实解误差界，也不自动消除 G48 低质量单元风险。

候选设置来自已有投影/孔隙敏感性结果，并非新的物理几何。此次不改 c 去拟合反力，不用体积分数归一化掩盖响应差异。

## 四步执行顺序

### 第一步：统一对照定义，锁定最小实验清单

**问题：** 已有结果是否在比较同一个几何、材料和宏观加载？哪些证据还缺？

复用均匀基准、独立单元矩阵对照、投影敏感性、背景加密和二值实体结果。逐项核对模型定义、程序版本、输入哈希、反力符号、体积与能量口径，整理一张对照表。二值体积分数、投影体积分数、贴体网格体积分数分别列出。既有改变 c 的体积分数匹配实验只用于解释，不能混入同几何验收。

以 `K=|F_z|/|u_z|` 为主要响应，记录 `F_z`、应变能和平均应力作一致性核查。归一化表观模量使用完整单胞面积与长度。原生 C3D8+USDFLD 尚未完成，B2 只有 JAX 解析证据；如实保留这些缺口，不因旧路线图而额外搭建工具。

**完成证据：** 一张可追溯的已有结果表、一份本轮工况/判据清单。若发现定义不匹配，先纠正比较口径；不提交新求解来替代核对。此步原则上零新计算。

### 第二步：只补候选设置的三个 JAX 工况

**问题：** 已出现的 1.234% 差异是否在网格变化和横向自由条件下仍成立，而非单个工况的巧合？

固定 `c=0.541062、β=40、η=1e-4`，复用 N64 fixed，仅补：

| 新工况 | 用途 |
| --- | --- |
| N48 fixed | 与已有 N64 fixed 检查该候选设置的网格敏感性 |
| N48 free | 建立自由横向的较粗网格结果 |
| N64 free | 检查自由横向响应及 N48→N64 变化 |

沿用已验证的 PETSc CG/GAMG 路径及容差，复用横向松弛求解器，不复制 FEM。记录求解收敛、周期约束、约束缩减残差、顶底反力、能量恒等式；free 另核对平均横向应力。新工况须通过现有物理一致性判据，不能只以进程退出码判断成功。

保存每个工况的实际参数、体积分数、响应、运行日志、运行时间和资源信息。自由松弛内部求解次数单独记录，三个工况不意味着仅三次线性求解。原 `m4_numerical_study.csv` 保持不变。

**完成证据：** 三个成功工况与 fixed/free 各一项网格变化量，或明确的失败原因与日志。新工况上限为三个；已有结果不重复运行。求解异常先核查实现或资源，数值判据失败则记录失败，不自动扩至 N>64、β>40、η<1e-4 或全参数扫描。

### 第三步：用现有 Abaqus 实体证据作独立比较

**问题：** 候选背景模型接近真实二值实体到什么程度？参考模型本身还有多少不确定性？

复用 Abaqus G24/G32/G48 的固定/自由结果，以及同几何 FE 加密、网格质量试验和体积估计。先检查 G48 的求解完成记录、PBC、反力平衡、能量和警告，再与第二步逐工况比较 K、Fz、能量及体积分数；必要时只重新提取已有 ODB。

分别列出背景网格变化、投影/虚拟孔隙影响、实体参考的几何/FE 敏感性。刚度、反力和固定加载下的能量差高度相关，不能算成三份独立精度证据。已有网格变化量不可直接相加为严格误差上界，也不能宣称 G48 就是真值。

**完成证据：** fixed/free 两个独立对照结果与参考局限说明。本轮默认零新 Abaqus 作业；若现有警告或参考不确定性使结论无法成立，结论写为“参考不足/待补证”，不自动追加更大贴体网格或改为壳模型。

### 第四步：作出本轮判断，冻结可复现基准

**问题：** 目前能支持怎样的计算能力，哪些条件仍不能保证？

按下面预先记录的工作判据，给出“本基准通过”“仅部分工况通过”或“尚未通过”，说明依据及剩余风险。即使失败也应形成研究结论，不以不断加算取代判断。

若通过，锁定这组几何、边界、数值设置和运行方式，作为后续研究的受控基准；若仅 fixed 通过，适用范围只写 fixed。报告计算时间/资源，并说明编译、求解、硬件和线程口径；现有运行记录不足以支持公平速度比时，不声称加速。

产出一份简洁结论报告、一张汇总表和可复现运行入口。复用已有核心模块；仅在执行确有需要时增加一个薄的工况驱动，轻量记录纳入 Git，原始日志/ODB 保留可追溯位置。同步研究状态及文件地图，不新增另一套规划文档。

**完成证据：** 本轮结果、成功范围/失败原因、候选设置与资源记录齐全。随后停止本轮扩展，依据这些结果再制定下一轮不超过四步的计划；不自动启动 M5、更多构型、训练或逆向设计。

## 本轮工作判据

这些是本轮采用的工程工作判据，不是数学误差保证，也不是用户过去指定的通用精度要求；执行前记录，不能事后放宽使结果过关。

背景网格变化取 `|K48-K64|/|K64|`；独立对照差异取 `|K_JAX-K_G48|/|K_G48|`。

| 项目 | 判据及解释 |
| --- | --- |
| 求解及物理一致性 | 必须通过现有残差、周期、平衡与能量检查；free 还需平均横向应力检查 |
| 候选背景网格变化 | 相邻网格刚度相对变化≤1%，≤0.5% 为较好结果；这是分辨率指示量 |
| 实体参考稳定性 | 现有几何/FE 加密的主要全局变化≤1%，警告与体积偏差须报告；不足则不作达标判断 |
| 背景与实体差异 | fixed/free 分别计算相对刚度差，以 G48 为分母，工作目标≤2%；同时报告参考不确定性，不能称真实误差已被严格控制在 2% |
| 适用范围 | 仅当前一个 Gyroid、当前 c、材料和加载的轴向线弹性响应；不外推到其他形态或非线性曲线 |
