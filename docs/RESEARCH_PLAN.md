# 唯一近期规划：大压缩差异、机制与最小能力验证

修订：2026-10-05。新四步均未启动。本次用户要求调查、整理并提出下一步；本次不提交新力学作业。已完成薄壁四步的原文已归档，原1%/5%前向与厚度梯度、10%未接受/20%未提交的事实不变。长期背景见 [研究背景](RESEARCH_BACKGROUND.md)，证据和算法解释见 [综合报告](TPMS_RESEARCH_REVIEW.md)，执行状态见 [当前状态](RESEARCH_STATUS.md)。

本轮问题：**t/L=0.05薄壁在XYZ周期、横向宏观应变固定的压缩下，10%差异来自哪里，向20%以上推进需要什么物理和求解能力？** 先前向可信，再一项有效梯度；不自动训练、全构型求导、重开边界比较或全面网格/eta扫描。约15分钟主要尝试可接受，实际成本与科学失败分开；路径成本和单点成本分开，保留内存和物理保护。

## 第1步：利用已保存10%状态定位差异

复用step3_xyz的JAX状态、壳ODB和输出，审查外功/储能/人工能、Equation控制反力定义、帧采样及壳厚度/平面应力假设。现有14.19%是与壳的反力差，壳质量差1.294%尚未过；先确认参考，不把壳当真值。

检查壁内与软域的F/J、变形梯度条件指标及空间位置，比较面积加权局部位移/弯曲。用候选间隙和必要几何精查判断壁厚层面的接近、相交及周期镜像；排除相邻三角面和周期拼接邻居。局部采样筛查不冒充全局接触证明。不默认做大规模全局特征谱或新FEM。

交付：已证实/待验证/参考未知的原因表与下一步所需机制。若现有输出无法解释1.294%参考质量，就明示未解决，转第2步独立时间积分检查；不放宽门槛或调物理输入凑过。只有明确缺失输出确实阻碍判断才补一次针对性提取/计算。

## 第2步：建立匹配Abaqus Explicit参考与机制范围

新目录锁定同一中面、L=10mm、t=0.5mm、XYZ宏观F_bar=diag(1,1,1-a)、E=10MPa、nu=0.3及Neo-Hookean。真实质量密度及单位另行明确，使用平滑宏观幅值与正确Equation控制节点；先接回1%/5%稳定静态参考，再审10%，参考质量成立才到20%。不拿旧摩擦压板/塑性模型直接比较。

若目标是准静态，核对主要阶段ALLKE/ALLIE、完整外功/能量、人工/黏性能量、接触穿透及反力。先用主要阶段动能≤内能5%作工作目标，初始低内能和失稳瞬时峰值单独解释；在一个关键区间将加载持续时间加倍，代表力/功变化≤2%作速率复核工作门槛，同时模式合理。不是只看终点比值，不用质量缩放/阻尼掩盖路径变化；这两个数字不是通用精度认证。

周期位移不自动包括周期镜像接触。若第1步或过程显示接触需要，明确壳厚和周期接触，先无摩擦力学基准；无接触证据不盲加接触。真实塑性压溃/吸能需求须另锁定材料参数，不自动替换本构。

交付：Standard/Explicit稳定段是否吻合、10%/20%的参考质量和机制范围。若参考不能成立，先收口未知，不让JAX拟合一个质量不明的答案。

## 第3步：只补证据证明必要的JAX能力

由前两步选择最小路径，不预定全部实现：

- 表示或普通软域是主要问题：做一个针对性表示/能量处理，透明记录模型改变和接触前偏差，不提高eta或加厚拟合参考，不全面扫描网格。
- 失稳路径需要动力推进：复用现有内力与Gauss本构，最小增加质量、稳定时间步、中央差分及XYZ动态缩减。先均匀体/已知动态基准，再接回薄壁1%/5%；速度/加速度、仿射加速度与动态反力必须正确。
- 壁接触是必要机制：只选一条可微接触路线，优先评估适合背景的TMC；先简单三维无摩擦基准对照，检查附带力、穿透、接触刚度、正则化能与导数。官方二维硬分组/历史变量不能直接视为三维连续设计认证。

若机制同时要求，可组合已验证能力，但不复制FEM、不预搭多平台、训练或通用接触框架。dynamic_relax_solve不是现成XYZ物理Explicit。塑性若确属最终目标，单独明确内变量、标定与路径导数后再纳入必要范围。

交付：一项有明确基准和适用范围的能力，或者确切方法限制。未通过基础/接触前验证不进入TPMS大压缩比较。

## 第4步：较大压缩前向对照后，只检一项有效梯度

以通过参考质量的10%/20%区间比较曲线、压缩功、主要模式、峰值/平台及接触开始；近零力用代表特征力归一化，分支跳跃不能只逐点百分比拟合。≤10%作为阶段响应差工作目标，≤5%作为后续更强目标，不预先保证20%达到。物理机制不一致，即使曲线接近也不通过。

先前向，再选一个通过的大压缩点/路径做厚度正负扰动。无历史稳定弹性终态可论证静态伴随；动态力、摩擦或塑性目标要处理完整时间/增量历史、接触事件和内变量。复核总导数，而非固定状态偏导；只验证一个目标，不启动训练或全构型优化。

交付：较大压缩的可信范围、机制/成本及一项梯度证据。若参考质量、接触或路径不可用，保存最后可信范围并另议，不宣称四步必定认证20%真实塑性压溃。每步结束更新状态与索引，下一轮由实际证据决定。
