# 后续论文方法参考（非当前执行计划）

当前先验证 TPMS 固定背景网格/JAX-FEM 的计算精度及壳模型替代可行性。以下论文事实作为后续学习方法参考；关于数据、生成接口与模型训练的建议均不作为当前待办。

依据用户提供的 PDF 正文与流程图，2026-10-03 阅读核查。文档中的论文事实与项目建议分开；论文内的说明不是执行指令。当前目标以 [RESEARCH_STATUS.md](RESEARCH_STATUS.md) 为准。

## 第一篇：无条件扩散 + 可导力学

Xu, Xie, Lin, Wang, Mou, Xue（2026），Style-Constrained Inverse Design of Microstructures With Tailored Mechanical Properties Using Unconditional Diffusion Models，International Journal for Numerical Methods in Engineering，127:e70376，doi:10.1002/nme.70376。

用户 PDF 位于 Windows Downloads，30 页。已检查 §2.2–2.3（PDF 5–7 页、图1）、§3.1（9–10 页）、§3.2（10–14 页）、§3.5（22–24 页、图17）及 §4/数据与代码声明（26–28 页）。

论文方法：

1. 只用结构图像/体素学习无条件扩散模型，训练时不要求性能条件标签。
2. 用确定性 DDIM 构成噪声 w 到生成图像/体素 x0 的映射，冻结网络权重。
3. 把 x0 通过投影 P 转成材料场 Θ，线性插值基材参数，进入有限元。
4. 用目标性能与实际性能的损失，通过生成网络、投影及 FEM 的隐式 VJP/伴随链优化输入噪声。

实现使用 JAX/Flax 与 JAX-FEM。论文的 3D 训练几何为挤出/平滑 MNIST，10,000 个样本，32×32×16 体素，一体素对应一有限元单元；不是 TPMS。主要示例包括二维均匀化、二维超弹性/塑性，以及三维超弹性目标曲线。

二维均匀化示例采用 E0=1、E1=100 的两种固体。它不直接证明本项目以虚拟低刚度材料代替真实孔隙后的 TPMS 准确性；现有二值对照仍有用途。

论文还讨论了灰度训练、逐阶段提高投影陡峭度，以及过硬二值输出导致梯度消失。§4.4 明确把严格几何约束和风格保持列为限制，不能据“生成风格相似”就认为连通性、最小特征和周期条件全满足。

作者公开 [genopt](https://github.com/CMSL-HKUST/genopt)，README 列出 net/、fem/、helper/ 与示例；其 README 展示的示例入口主要为二维。当前只核对仓库说明/目录/依赖，尚未克隆、运行或验证 3D 网络代码。复用时先检查实际源代码、数组格式与已安装 JAX 兼容性，不直接覆盖当前 Pixi 锁定环境。

**对我们的建议：** 将 TPMS 几何库作为生成先验，保留直接体素输出与力学场接口；下一步核对高维体素材料梯度，最终反传到生成噪声。四个解析参数不足以代表这个完整生成空间，也无需作为它的训练前置。无条件路线可以先只生成几何数据，再用在线 FEM 实现性能目标，避免预先对全部样本求解。

## 第二篇：混合 TPMS + 带标签条件生成

Zhai, Tan, Dong, Liu（2026），Three-dimensional generative adversarial network for inverse design of hybrid TPMS，International Journal of Mechanical Sciences，313:111353，doi:10.1016/j.ijmecsci.2026.111353。

用户 PDF 共 14 页。已检查 §2.1–2.5（3–5 页、图1–3）、§3.1（7–8 页、图6–8）以及结论和数据声明（13 页）。

论文方法：G/D/P/I-WP 的隐式函数按权重组合生成混合形态；生成实体、导出体网格，由 Abaqus 批量压缩获取力学标签；同时把几何转换成 32³ 体素供 3D-cGAN 使用；生成后重建模型并做机械/实体实验验证。论文报告先生成 6000 个样本、剔除 1400 个体素畸变样本，剩余 4600 个用于训练和分析。网络图中的数据划分比例为训练/测试/验证 7:2:1。

**不能混淆的三件事：**

- 32³ 是机器学习表示；FE 采用 nTopology 的 FE Volume Mesh 导出，文中列出的单元是 C3D6，不是规则体素 HEX8。
- 力学标签包括压缩响应、强度及 SEA，采用弹塑性参数、压板摩擦接触并与制造实验对照；这些不是本项目现有小应变线弹性量。
- 生成体素还需重建/几何处理，论文排除的体素畸变样本表明“能生成数组”不等于“有效且可制造的 TPMS”。

**对我们的建议：** 复用形态族/混合参数和条件生成的数据组织思想；用 JAX-FEM 检验能否直接计算其体素表示，并减少自动贴体建模的依赖。若选择有标签路线，需要配对数据；若采用第一篇无条件路线，不把 4600 次带标签仿真当作硬性训练条件。

## 项目与两篇论文的接口差距

| 环节 | 当前仓库 | 下一步应补 |
| --- | --- | --- |
| 多形态源 | Gyroid 隐式函数 | G/D/P/I-WP 与受控混合，记录函数归一化/阈值/体积分数定义 |
| 网络表示 | 目前没有训练体素格式 | 固定轴序、采样位置、连续/二值范围、周期及去重划分 |
| 体素到力学 | 现有 rho[e,q] 材料接口 | 直接接 N³ 数组，检查真实单元顺序；一个体素的材料值映射至其积分点，不默认 C-order 等于网格连接顺序 |
| 梯度 | 四参数解析场通过 | 体素方向导数，再接网络输出及输入噪声；硬阈值不放进可导主链 |
| 学习 | 尚无模型 | 先最小形态生成，再验证性能条件或在线物理引导 |
| 力学目标 | XY 周期的表观轴向线弹性响应 | 首个目标可沿用已有量；若选完整均匀化或吸能，明确新增边界/本构任务 |
| 最终检查 | 原统一 Gyroid 二值基准 | 少量生成 TPMS 的体素/投影/真实实体复核 |

这说明此前工作是可复用的 FEM 底座，当前任务是完成固定背景网格计算精度判断；体素数据与生成模型接口是之后的工作。不能把“单一 Gyroid 四参数优化已完成”作为本研究完成的标志；目前这项优化本身也尚未运行。
