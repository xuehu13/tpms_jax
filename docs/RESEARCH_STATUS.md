# TPMS 体素计算、形态学习与生成式逆设计：当前研究主线

更新：2026-10-03。以用户本次明确纠正的目标为准。此前 2026-10-02 总览将目标收窄成“四参数恒体积刚度优化”，这是助手的方向错误；其中 R1–R4 四阶段计划已撤销，不能继续作为当前待办。历史原件在 Git 提交 `6774e17` 和 Windows `work/archive_20261003/superseded_plan/` 保留。

## 1. 目标

用户明确的主线是：**参考两篇指定论文，检验 TPMS 能否采用体素方法在 JAX-FEM 中可靠计算；在可行基础上，学习不同 TPMS 形态或参数与力学响应的关系，进一步尝试扩散模型等生成式逆设计。**

目标流程：

**多种/混合 TPMS 几何与参数 → 统一体素表示 → JAX-FEM 力学计算与必要梯度 → 形态学习/性能学习 → 按目标性能生成 TPMS → 独立力学复核。**

四参数 Gyroid 优化不是项目终点，也不是训练扩散模型的必需前置。它只是一项已完成的低维梯度检查，保留作参考。目前也没有确定论文必须围绕“刚度最大化”；目标性能匹配、生成多样性及形态保持才属于两篇论文所指向的生成式路线。

## 4. 对此前工作的重新评价

均匀解析基准、同离散方程对照和二值实体抽查是可复用的基础，支撑“TPMS 体素 + JAX-FEM 能否可靠计算”。梯度检查也有用，因为第一篇的方法确实需要可导 FEM。

但此前在单一 Gyroid 的网格、β/E_min、体网格质量和低维参数导数上投入了过多连续阶段；尤其把“四参数恒体积刚度优化”设为研究终点，偏离了用户的生成式目标。接下来不继续该优化、不自动补自由横向四参数导数、不以局部应力收敛或二值极限为单独主课题。

已有计算证据保留，作为接口选择和误差判断的依据。Abaqus 用于少量代表性独立验证，不代替批量 JAX-FEM 计算，也不需要每个学习样本都做一次二值贴体对照。

## 5. 正确的后续顺序

以下是依赖关系，不是已经执行或预先保证完成的训练任务。模型规模、样本量和标签在小批实际运行后确定，避免先承诺几千个力学求解。

| 阶段 | 工作 | 交付与推进条件 |
| --- | --- | --- |
| G1 通用体素计算接口 | 直接接受任意 3D 体素/连续材料场，固定数组轴序、单元对应、孔隙刚度和体积定义；统一完整单元、二值体素及平滑体素的意义；做少量前向及体素方向梯度核对 | 网络输出能直接进入 FEM，不需拟合四个参数；保存正确的轴序/场映射及梯度检查 |
| G2 多形态与小批数据试验 | 建立 G/D/P/I-WP 及受控混合形态，采样体积分数/阈值和混合权重；先小批，核对几何有效性、周期性、体素解析度、响应范围与求解成本 | 确定一个可用的样本格式与实际资源预算；按几何家族/参数去重划分数据，避免同一结构换采样后跨集合泄漏 |
| G3 形态学习与生成 | 优先评估第一篇作者代码的可复用部分，训练 TPMS 无条件扩散的最小模型；另一条条件模型路线按需要使用有标签样本 | 未引导生成能覆盖训练形态且有合理多样性；检查周期边界、连通性、体积与灰度/二值差异，不只看网络 loss |
| G4 目标性能逆设计 | 无条件路线：冻结网络参数，经 DDIM/投影/FEM/VJP 优化噪声以匹配目标性能；条件路线：用力学标签训练条件生成并以 FEM 验证 | 完整链可用；在独立目标/初始噪声上评价匹配误差、形态保持和多解性；不把直接四参数优化当作扩散逆设计 |
| G5 结果验证与科研结论 | 用 JAX-FEM 重算生成结构，检查投影/阈值/网格改变后的性能；少量代表设计再作 Abaqus 二值实体复核 | 区分生成误差和力学代理误差；记录目标达成与失败，结合直接相关研究评估贡献 |

**下一项具体工作是 G1，再用 G2 的小批样本检验数据与计算成本。** 不是重开整个基准验证，也不是立即启动大型训练。当前没有额外模型训练或 Abaqus 任务在后台运行。

## 6. 两种学习路线共用底座，但数据需求不同

- 路线 A：无标签 TPMS 几何库 → 无条件扩散；设计时通过可导 FEM 优化生成噪声。它需要几何训练样本及在线 FEM/伴随计算，不需要预先为全部几何算力学标签。这是第一篇的核心思路，也是首先评估的方向。
- 路线 B：TPMS 体素与力学标签配对 → 性能预测器/条件生成模型。它需要覆盖目标范围的力学数据库，可参考第二篇的 3D-cGAN，也可考虑条件扩散。暂不并行实现两个大型模型。

两条路线都保留“体素计算可行 → 多形态表示 → 学习/生成 → 性能复核”的原目标。选择不会把研究再收窄成只有一种 Gyroid、四个参数的最大刚度问题。

## 7. 必须明确的力学与表示边界

- 当前 JAX-FEM 问题是小应变线弹性、XY 周期和平整顶底加载面；现有 Eapp 是该边界下的表观轴向响应。它可以作为最小学习演示的一个性能量，不能标作完整均匀化弹性张量。
- 若后续学习完整 3D 均匀化弹性张量，需全 XYZ 周期和六个独立宏观应变工况。已有 pbc.py 支持 XYZ 映射，但多形态的完整张量计算/梯度仍需针对性核查。
- 第二篇的 SEA、压缩平台和峰值等来自大变形、塑性和压板接触的压缩响应。现有线弹性应变能不能冒充该吸能标签。首次学习演示可从已验证的线弹性量开始，完整吸能路线属于之后需明确实现的力学扩展。
- 当前 Gyroid 是解析密度在每个真实 Gauss 点求值；生成模型通常输出单元/体素值。这两种离散材料场不同。G1 需固定体素 → 积分点映射，不能把老 Gauss 结果直接当成新体素标签。
- ρ 是刚度插值代理；二值实体体积、二值体素体积、平滑投影体积分别记录。陡峭投影可造成梯度消失，网络生成的近二值场也不保证有效连通和周期拼接；这些应在生成流程中实查。
- 目前没有证明“TPMS + 扩散 + JAX-FEM”本身一定新颖。先做可行性和方法接合，贡献由完整原文对照及最终结果判断。
