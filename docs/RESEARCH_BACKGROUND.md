# 长期研究背景与范围

更新2026-10-13。研究目标是用JAX-FEM在固定背景网格上可信地计算薄壁TPMS受压响应，并把力学目标对几何设计变量的有效梯度传回，为后续构型和参数学习、逆向设计打基础。当前优先确认仿真与梯度可行性，训练后置；没有预设数据规模、网络架构或异质材料目标。

固定背景的价值是减少设计变化后的贴体网格重建。当前周期三角中面的真实距离带表达名义壁厚，sigmoid占据是几何近似，孔隙弱域是数值处理，基材本身均质。典型单胞L10 mm、壁厚0.5 mm；N32主线保留HEX27。方法和假定集中于TPMS_RESEARCH_REVIEW.md。

研究要分别满足三个层次：前向响应可信；同一离散模型的总导数正确；沿梯度改变结构后，独立参考或真实结构也呈现预期改善。前向接近不保证梯度正确，AD/FD一致也不自动证明真实结构准确。Abaqus壳是有自身近似的工作参考，不是真值。

共同中面端缘等效压板、XY周期和自由横向宏观伸缩下，G/P/diverse_04已有受控前向宏观通过证据。28的幅值偏高、02的峰后动态差异、05的HEX27末段缺失和D的局部模式及参考失败仍保留。当前没有完整壁面或自接触认证，不能普遍承诺任意构型0至20%误差均在10%以内。

梯度方面，r53的厚度、界面及一个旧形态坐标a已有分目标证据，失败和原门槛保持；包含a的完整三参数反向未执行。新增r57/r58验证真实diverse_28的(c1,c2,c0)：0.5%和10%的完整加载功VJP均通过，10%最大AD/FD差0.00285%；10%瞬时力尚未通过。三个原始坐标只有两个独立形态自由度，不能称任意方程或拓扑均已验证。

一次研究一个因素，不通过厚度、模量、阻尼或界面参数拟合参考。约10%响应差是限定工作目标，导数门槛按各独立协议保持。正式程序仅WSL /home/xuehu/projects/tpms_jax；Windows为阅读、报告和历史。当前无新队列，未来建议不自动启动。当前事实见RESEARCH_STATUS.md，唯一安排见RESEARCH_PLAN.md，原证据位置见FILE_MAP.md。
