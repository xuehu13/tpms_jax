# 长期研究背景与边界

目标是在JAX中可信地计算薄壁TPMS的压缩响应，并保留从力学响应传回几何设计变量的有效梯度，为以后构型/参数学习、生成和逆向设计提供基础。当前优先解决仿真可行性，训练后置；不预设网络、参数数量或样本规模。

核心问题是：在固定背景六面体网格上，以连续占据场表示一个受控薄壁单胞，能否得到可信的0–20%压缩曲线，并在几何以解析场或数组输入时保留响应与正确设计梯度？Abaqus壳/Explicit是工程参照，可信保形实体有独立判别价值，壳本身不是真值。

代表构型为diverse_28，迁移构型diverse_04。当前单胞边长L=10mm、物理厚度t=0.5mm；仅借用户原壳中面，不照搬原厚度、塑性或摩擦压板。材料为Neo-Hookean，E=10MPa、ν=0.3。压缩采用XYZ周期波动、宏观横向应变零，未来边界方式比较另行安排。

占据场是几何的数值近似，软孔隙是人工计算域，均不表示用户要研究异质材料。恒厚距离带与早期Gyroid阈值c模型不同，c不能称恒定厚度。占据在参考Gauss点计算并附着材料点；网格拓扑固定不等于变形时位置固定。

当前N32、HEX27、27个Gauss点、HRZ集中质量与共享材料/内力、一个显式入口保持。默认NH不变，objective_void/C²显式选用。η=1e−4，界面10–90%宽度0.05mm，φ=0.001/0.01分界和虚域正截点最大0.1规则保持。真实F/J不夹断，主要实体φ≥0.01要求实际J>0。

用户授权的r37/r38仅作界面宽度0.025/0.05/0.10mm初始诊断，不改变上述生产基线，不以接近壳作为挑选参数的依据。

约10%是限定范围内的工作目标，约5%是改善方向，均非行业精度认证。初始偏差不能自动解释峰位；允许跳跃时动能升高，但材料无定义、步长失控和无解释能量增长不能称正常跳跃。周期约束和软孔隙都不构成自接触律。

目前有限范围前向可行性已有证据，通用20%和完整设计AD尚未认证。原NH10%/15%厚度总导数通过，20%符号失败；新核局部/短块导数不继承完整路径认证。形态预处理的最近三角面选择还不是有效形态AD。详见[综合说明](TPMS_RESEARCH_REVIEW.md)。
