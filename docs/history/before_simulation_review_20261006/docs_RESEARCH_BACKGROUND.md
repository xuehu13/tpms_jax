# TPMS研究背景与边界

长期问题：较薄TPMS能否在体素/固定背景上由JAX-FEM可靠计算压缩响应，并提供有效梯度，服务构型/参数学习、生成及性能驱动逆设计？先建立力学与导数的可信范围，再开展训练。方法调查及判断看[综合说明](TPMS_RESEARCH_REVIEW.md)，下一项只看[主规划](RESEARCH_PLAN.md)，事实看[状态](RESEARCH_STATUS.md)。

## 锁定的研究口径

- 当前目标diverse_28中面，L=10mm、参考厚度t=0.5mm（t/L=5%）；原用户壳厚0.328595mm仅是历史参考，不再作为目标。只复用中面，不照搬塑性/摩擦压板。
- 用户决定统一XYZ三向周期压缩，宏观横向应变固定。研究周期材料内部响应，压板试样差异后置。
- 当前均匀Neo-Hookean基材、E=10MPa、ν=0.3、无接触/塑性。连续占据和虚拟孔隙是几何/数值近似，不是异质材料课题。
- 固定背景指参考连接关系固定，有限应变节点照常运动，材料占据保持在参考积分点。当前HEX27候选属于同一背景方法；壳不是自动微分理论所禁止，只是当前JAX-FEM没有维护壳实现。
- 大压缩目标包括20%以上，但比例不自动决定接触、屈曲或塑性；普通小模量孔隙不构成接触定律。

## 如何判定研究可行

需要同时看前向、独立对照、有效总梯度、物理适用范围和成本。完整均匀体或小网格成功不能替代目标薄壁证据；已知答案反推不等于训练；厚度导数不等于形态导数。文献可行性、本项目验证和未来假设分开。

前向约10%是本轮可行性工作目标，完整精度收敛后置；不能调厚度/提高η拟合参考，不能把原始失败改成成功。约15分钟主要尝试可接受，旧100/300秒门槛不沿用；前向路径、反向及扰动验证的成本分别记录，预算停止不叫方法失败。

当前前向目标已通过，完整厚度扰动已完成；10%/15%路径总导数核对通过，20%保载总导数实际验证未通过；当前主线是解决虚域变分响应放大。生成器可输出构型参数、隐式场或数组，不预设四参数上限、固定网络输出形式或几千个算例。梯度的潜在收益是性能损失能够回传设计，不保证前向一定更快或梯度总是存在。
