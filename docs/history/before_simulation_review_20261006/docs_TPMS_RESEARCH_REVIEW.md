更新：2026-10-05。前向证据冻结于51136a5；本轮补齐原大压缩第4步的厚度路径/导数验证。最新执行见[厚度路径与梯度记录](GRADIENT20_PROGRESS_REPORT.md)，任务与接受范围见[主规划](RESEARCH_PLAN.md)。

## 1. 目前能作什么判断

长期目标是让较薄TPMS在固定背景上由JAX-FEM计算压缩响应，并提供能用于构型/参数学习及性能驱动逆设计的梯度。当前先建立力学与导数的可用范围，训练后置。不是研究异质材料，也不预设只能四个参数或必须生成几千个样本。

**已有证据支持这条路线继续推进：同一目标薄壁已算到20%，二次背景表示达到本轮前向工作目标，加载速率影响很小。完整JVP已执行，10%/15%导数核对通过，20%保载及损失总导数未通过。前向可行不等于20%已经具有可用设计梯度。**

| 研究问题 | 实际证据 | 当前判断 |
| --- | --- | --- |
| 小变形能否计算目标薄壁 | XYZ线性壳对照刚度差4.979%，主要模式相近 | 工作初筛通过 |
| 能否计算大压缩 | HEX8及HEX27显式均实际达到20%并保载 | 前向可计算性成立 |

| 梯度是否能算 | 旧HEX8在1%/5%的厚度总梯度核对通过；20%中心平衡及伴随方程已求解 | 自动微分和伴随基础有项目证据 |

## 2. 实际计算的是什么模型

目标中面取自diverse_28；只复用其几何，原壳厚、塑性和摩擦压板没有照搬。单胞边长L=10mm，参考壁厚t=0.5mm，所以t/L=5%。材料为均匀Neo-Hookean弹性基准，E=10MPa、泊松比ν=0.3。这里E控制基材刚度，ν控制横向与体积变形；并未声明这是用户最终打印材料的实测本构。

背景为完整规则实体网格。对每个**真实参考Gauss积分点**计算距周期中面的距离d，再用光滑占据：

φ(d,t)=sigmoid((t/2−d)/ℓ)，sigmoid(x)=1/(1+exp(−x))。

φ接近1为材料壁，接近0为空隙，界面附近在两者间过渡。ℓ=0.05mm/(2ln9)，使φ从10%到90%的物理过渡宽度为0.05mm。用s=η+(1−η)φ乘原基材能量，η=10⁻⁴为数值刚度下限；远孔隙的等效E约0.001MPa。连续占据是几何近似，虚拟孔隙用于保留固定网格和连续参数映射，它不是另一个真实材料相，也不是已建立的接触介质。

积分点不是各自独立的小弹簧。单元节点位移经形函数计算每个点的变形梯度，再计算该点的应力与能量；按积分权重相加并组装到节点内力。积分权重JxW由参考单元映射与Gauss权重构成。占据保持在参考材料点上，变形后不在当前空间重新填材料。固定背景指参考连接关系固定，节点在有限应变计算中照常运动。

XYZ周期使用u(X)=H X+w(X)：X是参考坐标，w是在相对面相等的波动位移，H=diag(0,0,−a)。a为宏观压缩比例，20%对应轴向长度由10mm变成8mm，宏观缩短2mm；横向宏观应变固定为零。周期单胞内部可以弯曲和产生局部变形，这个边界不是摩擦压板试样。今后仍采用用户选定的XYZ口径，不重开两种压缩方式比较。

Abaqus参考是同一中面的S3R壳，9351个节点、17986个三角形、五点截面积分，物理空隙没有单元。当前壳厚也为0.5mm，基材参数和宏观加载匹配，双方均无接触和塑性。因此它们是对同一目标薄壁的**壳和背景三维实体两种近似**，不能把二者差异都归为JAX求解错误。壳XYZ方程由本项目生成，并非照抄用户旧摩擦压板约束；具体2196条方程、控制反力和单位见执行记录。

## 3. 问题是不是出在单元类型

最合理的判断是：**薄壁位移表示是此前偏硬的重要候选原因，二次表示已被实际结果证明有明显价值；现有试验没有证明它是唯一原因，也没有完成单独的锁定因果分解。**

原HEX8的一阶位移近似在单元内较难表达弯曲。全积分一阶实体在纯弯曲中可能产生不应有的剪切应变，表现为弯曲过硬；二次近似更能表示曲率。这是有限元理论和Abaqus官方弯曲基准支持的机制。[官方全积分说明](https://docs.software.vt.edu/abaqusv2025/English/SIMACAEGSARefMap/simagsa-c-ctmfull.htm)。

本项目没有靠加厚、提高孔隙模量或修改E拟合：

| 比较项 | 原HEX8 N64 | 当前HEX27 N32 |
| --- | ---: | ---: |
| 单元数 | 64³ | 32³ |
| 每单元节点/体积积分点 | 8/8 | 27/27 |
| 全背景节点 | 两者均65³=274625 | 同左 |
| 积分占据体积分数 | 15.16492% | 15.16338% |
| 20%反力相对慢壳参考的差 | 22.41% | 9.45%（慢加载） |
| 整段曲线差/输入功差 | 13.47%/15.51% | 5.87%/6.87% |

N是每轴单元数，不是参数数目。二次单元含边/面/内部节点，N32和一阶N64的节点数相同；它仍属于固定背景方法。HEX27单元宽0.3125mm，节点间距0.15625mm；不能把节点间距与单元宽混用，宣称有3.2层二次单元穿过0.5mm壁厚。倾斜薄壁的覆盖也不能仅由t/h推断。

积分点布局与二次质量集中也一起变化：普通局部行和质量有非正项，改用HRZ正对角集中，按单元总质量归一化，并未进行质量缩放。新的积分占据总用料仅相对改变约0.0101%，不能用总用料增减解释这次力学改善；局部界面积分与壳/实体运动学差异仍可能有影响。

另一个证据是原生Abaqus背景桥接：同一HEX8 Gauss占据、同一保存20%节点位移被指定时，内部宏观反力/能量与JAX差1.13%/1.08%。这削弱了“大单位/本构/占据实现错误直接造成22%差异”的解释。所有位移被指定，该桥接**不是独立平衡曲线**，原生C3D8也有自己的体积积分处理，不能把1.13%与9.45%混成同一种误差。

Qiu等的TPMS壳/实体/体素比较说明，薄壁仅被一两层二值体素覆盖时可能漏掉连接特征，而某些较充分覆盖的体素模型能获得合理响应；壳也有适用边界。本地第11–13页已复核，包括图11、表5和图12/13。该文主要是删除空体素后的C3D8R、弹塑性/接触及试样模型，不是我们的光滑全背景HEX27，不支持把任何一种单元普遍宣布为最优。[Qiu等，2024](https://doi.org/10.1016/j.ijmecsci.2023.108657)。

## 4. 显式是不是合理的主要路线

**作为当前大压缩前向路线，合理且值得保留。已经在这个代表薄壁的两条路径中完成了计算；仍是有条件的稳定，不能宣布对所有TPMS或任意时间步稳定。**

静力Newton每个加载点需要求平衡并解整体切线方程。此前15%续算卡在线性迭代，20%厚度扰动又出现慢收敛/非能量下降方向。显式用集中质量和当前内力逐个小时间步更新速度、位移，不要求每一步求静力平衡，因而能绕开这类每步Newton阻塞。它计算的是运动方程；以足够慢的加载近似准静态，需要能量及速率证据。[Abaqus显式理论](https://docs.software.vt.edu/abaqusv2025/English/SIMACAETHERefMap/simathe-c-expdynamic.htm)。

本项目复用JAX-FEM材料单元核及组装，加入XYZ归并、仿射惯性、中央差分、HRZ质量和块回退减步。官方已有三维显式弹性波示例，只能作为基础实现参考，不是官方TPMS压缩认证。[官方示例](https://github.com/deepmodeling/jax-fem/tree/main/applications/explicit_dynamics)。

当前可靠性证据有三个层次：

1. 波检验、批处理等价核对及14项相关维护检查通过，排除已测试的基础实现问题。
2. 两条薄壁路径均达到20%及保载；约14%时各拒绝一个无效块并减半时间步，未删除正体积保护。初始步长约2.69×10⁻⁷秒，减步后约1.35×10⁻⁷秒；已完成状态均满足采样Gauss正体积要求。
3. 加载0.004与0.008秒比较，端点力/整段曲线/功仅差0.0573%/0.6067%/0.00591%，均小于事先指定2%；支持目前准静态响应对这一速率变化不敏感。

动能是运动储能，弹性能是变形储能；慢路径在压缩至少1%的采样加载时间均满足动能/弹性能不超过5%，保载末段该比值约0.0000600%。储能与积分输入功差约0.00196%。低动能不能独立证明空间精度，但结合速率复核支持准静态口径。[官方能量判断](https://docs.software.vt.edu/abaqusv2025/English/SIMACAEGSARefMap/simagsa-c-qsienergybal.htm)。

显式的稳定步上限随最高振动频率、变形和材料状态变化，初始波速估计不是完整非线性保证。我们的回退策略不是Abaqus成熟的全局自动估计器。二次单元也不是任意大畸变或接触问题的通用最佳选择；当前选型来自这个算例的实际改善。

![当前二次背景的快慢加载及Abaqus壳参考](../validation/large_compression_20261005_r6/quadratic_candidate/rate_response.png)

图中横轴是宏观压缩比例，纵轴是控制反力幅值。快慢JAX曲线几乎重合；JAX和壳参考均有先升后降的宏观软化趋势。相似趋势有价值，但下降段本身不独立认证屈曲机制或相同稳定分支。

## 5. 保留梯度优势的真正条件

单元改成二次、前向改用显式都不在理论上取消自动微分；形函数、占据、材料能量和时间更新仍可构成可微计算。默认前向初始化质量和占据；本轮增加可追踪HRZ质量/占据与响应接口，使它们显式传入同一时间推进核。文件读写和数值保护仍在外层，**给整个CLI直接套grad不会自动得到正确的总梯度。**

目前20%中心重新平衡成功：反力幅值2.004466N，缩减内力残差3.55×10⁻⁹，小于预定10⁻⁸；与慢显式保载平均反力只差约0.0062%。残差指未平衡的节点内力范数，不能当实体精度百分比。伴随线性求解约4.70分钟，得到了dFz/dt=−10.84494N/mm候选；压缩力为负，所以这个候选表示加厚后反力幅值增加。**它未通过独立扰动验证，不能用于设计。**

减薄至0.4975mm时，残差下降策略停在4.69×10⁻⁷；能量下降策略最终出现非下降方向，最后残差1.51×10⁻⁶。两种尝试含启动监护累计约134分钟，没有可用正负中心差分。该失败说明当前扰动重平衡办法不够可靠，不证明平衡不存在，也不证明导数不存在。切线负曲率只在未平衡扰动状态附近被提示，不能反推中心解已认证不稳定。

CG通常要求对称正定算子；正对角和一次真实残差通过不能证明整体正定。若附近切线非正定，MINRES等有更合适的线性适用范围，但仅换线性算法仍不保证Newton获得正确加载分支。隐式导数的数学条件是局部平衡映射可微且约束后切线可逆，并不要求所有切线都正定；稳定性与可微性仍需分开。[SciPy CG](https://docs.scipy.org/doc/scipy/reference/generated/scipy.sparse.linalg.cg.html)、[PETSc MINRES](https://petsc.org/release/manualpages/KSP/KSPMINRES/)。

本轮保留两条导数路线的区别；实际采用后一条：

| 路线 | 求什么 | 适合条件 | 当前状态 |
| --- | --- | --- | --- |
| 显式前向，平衡端点隐式伴随 | 选定弹性平衡分支的反力/性能总导数 | 末态充分平衡、局部光滑、切线可逆，扰动回到同分支 | 中心已求解，扰动验证未完成 |
| 对显式离散时间路径求导 | 按已定义加载/保载流程得到的响应或曲线损失导数 | 设计相关量全部进入时间推进，一致时间离散与目标，路径梯度经核对 | 完整路径实际执行；10%/15%通过，20%保载未通过 |

路径路线需要让厚度同时改变Gauss占据、内力、HRZ质量和宏观惯性；还要包括反力提取及保载平均。只对内力求导却冻结设计相关质量，得到的是另一个问题。减步、回退、采样和停止属于数值控制；第一次验证应在一致的有效时间网格上求导/差分，遇到无效状态则采用共同保守时间网格重新核对，不能忽略失败块或对任意if分支强求光滑。

当前只有一个厚度方向，建议先用JVP：它在推进状态时同步推进该设计方向的导数，不必保存每个时间步的全部历史。它是完整离散路径的方向总导数，不是差分，也不是固定状态偏导。[JAX自动微分说明](https://docs.jax.dev/en/latest/notebooks/autodiff_cookbook.html)。

本轮正负厚度从零加载，各自到20%及保载；三条接受网格完全一致，主要末态模式相近。实际JVP同时传播全部23586步状态、占据、HRZ质量、仿射惯性及减步半步速度重定位，目标包含保载平均。这是指定共同时间网格的离散路径导数，不是自适应拒绝/减步控制逻辑的导数。20%保载JVP为+76.093668N/mm，独立差分为-10.797551N/mm，符号不一致；不能用于20%逆设计。

未来很多几何/体素变量对应一个标量损失时，反向VJP/离散伴随更有价值。必须分块保存检查点并重算中间量；只给整个大循环套一个checkpoint并不会自动解决内存。当前周期状态仅位移和半步速度每步就约12.6MB，快路径23586步全部保存约300GB（十进制），还没算单元中间量，8GB显存不支持这种朴素历史存储。JVP先回答少参数可行性，之后再评估反向成本；不提前搭训练平台。[JAX检查点说明](https://docs.jax.dev/en/latest/gradient-checkpointing.html)。

本地Thillaithevan等的周期微结构非线性逆设计，已经把固定网格、周期波动、软孔隙和AD/伴随连接到目标应力曲线。正文使用二维平面应变、修正SVK、SIMP及静力求解；不等同于我们的三维薄壁显式，但说明研究路线有理论与实际先例。复核页4/5/7/8，不能误写为该文已经证明Neo-Hookean TPMS20%或Explicit梯度。[原论文](https://doi.org/10.1007/s00158-024-03761-7)。

对后续生成/逆设计而言，梯度优势是性能损失能经过力学计算回传至可微几何参数或占据场，再连到生成器。并不是AD使力学自动更准，也不保证比Abaqus前向快。多变量标量目标能避免逐变量做两次扰动，是潜在关键收益；本项目尚未实测这种高维反向成本。厚度导数即便通过，也不自动等于中面形态导数；最近三角距离/硬阈值/构型切换的导数接口需要后续单独处理。

## 6. 还有哪些疑虑，是否阻碍科研可行性

| 疑虑 | 已有事实及解释 | 当前优先级 |
| --- | --- | --- |
| 20%有效梯度与分支 | 正负完整路径及JVP已执行，10%/15%导数核对通过，20%保载与损失导数未通过；模式初筛相近但不是严格稳定谱证明 | 已定位虚域敏感性放大；论证修正方案，不延长失败Newton |
| 虚拟孔隙畸变 | Q2最小观察J约0.0345；保存快末态实体点最小约0.846、软域约0.0354 | 随路径保护与记录，若影响导数再作针对性处理 |
| 自接触及周期镜像 | 三条20%末态周期非局部三角/映射厚度初筛无包络重叠候选 | 近似末态初筛；非完整偏置表面或全路径接触认证 |
| 壳与三维背景的系统差异 | 光滑界面/软孔隙、厚度运动学与积分不同；参考也不是无误差真值 | 明示约10%工作范围，完整收敛后置 |
| 跨构型和几何导数 | 当前一个代表中面，旧其他构型结果不能替代当前薄壁20%验证 | 本轮梯度后再规划小范围扩展 |
| 梯度成本 | 前向约15.6分钟；单厚度JVP约50分钟量级，实际值看执行记录 | 单方向AD验证可行性；高维反向/检查点成本尚未实测 |

J=detF是局部当前/参考体积比。J=0.035表示该虚域积分点压缩到约3.5%参考体积，不是“整个TPMS压缩96.5%”，也不是实体材料都如此。软域大畸变是固定背景有限应变的已知困难；Wang等提出在实体使用有限应变能、虚域使用小变形能并插值，以缓解它。这改变了能量模型，必须验证实体响应和梯度偏差；当前未实现，不因存在文献就自动加入。[Wang等，2014，作者摘要](https://orbit.dtu.dk/en/publications/interpolation-scheme-for-fictitious-domain-techniques-and-topolog/)。

普通小模量填孔隙不等于自接触。TMC等文献通过专门接触介质和正则化处理内接触，能结合非线性力路径设计；只有实际壁接近/穿透成为主机制时才评估，并需三维及周期镜像参考。[Bluhm等，2021](https://arxiv.org/abs/2010.14277)。当前没有证据要求立刻加入摩擦、塑性、接触或额外稳定化。

壳参考能量检查仍有约1.33%总能量漂移和约1.43%人工能/外功，Standard的储能/外功差约2.08%；这是参考精度的实际边界，不能把它改写成严格通过。该百分比不能直接加减到9.45%反力差上。按用户先可行性的要求，它目前不阻止必要梯度探索，之后若要精度论文或真实替代需完善参考。

因此目前继续研究有充分理由，也存在明确可定位的剩余风险。本次20%总导数验证已执行且未通过；当前应优先论证虚域变分响应改进，不重复基准前向或先搭训练网络。若路径敏感性呈分支跳变，必须限定导数区间/定义可微路径目标；若软域先失效，再选择有依据的虚域改进，不能调η或厚度掩盖问题。
