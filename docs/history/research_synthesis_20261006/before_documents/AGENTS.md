# TPMS研究工作约定

继续科研前依次读[研究背景](RESEARCH_BACKGROUND.md)、[唯一近期主规划](RESEARCH_PLAN.md)、[当前状态](PROJECT_OVERVIEW.md)、[文件地图](FILE_MAP.md)。正式程序在WSL /home/xuehu/projects/tpms_jax；此工作区为阅读/历史。

- 长期目标是可信薄壁TPMS背景压缩和有效梯度，服务构型/参数学习、生成及性能驱动逆设计。训练后置，不预设四参数上限、固定网络输出或几千个算例。
- 最新用户指令优先，只执行当前主规划。仿真替代与JAX单因素改进优先，复用现有壳和简单工况，复杂三维参照/训练后置。四步仍为冻结定位、JAX改进、有限物理工况、范围/未来梯度。第2步材料域修复、代表快慢路径与速率门槛通过，可固定该版本进入有限工况验证；慢路径对壳反力/曲线/功差6.85%/5.05%/5.98%，快/慢10.74/21.14min；45项核/接入检查及6点局部AD/FD通过，快慢速率通过。新材料保持原φ=0.001/0.01界限、η/界面/厚度/实体NH，虚域J^(−2/3)作C²能量续接，截点最大0.1随占据趋零，实际F/J不夹断。严格NH区域φ≥0.01要求实际J>0，低占据混合/深虚域全F求值；新27/125点能量/应力有限，实际虚域翻转保留，不以正J子域和当总能量。required_positive_J_*域与旧NH_active_*域不同，不直接同比。候选默认仍未替换NH，固定为有限前向验证方法，证据VOID_CONTINUATION_PROGRESS.md、validation/void_continuation_20261006_r12。下一项仅第3步固定该方法，少量真实厚度工况需匹配壳参考；不重新建复杂三维模型。不追加积分/η/界面/网格扫描、不调参数拟合壳、不自动搭SVD/共转/非局部/混阶框架。r11材料域失败、r8积分和r9转动失败均冻结；r12初次FD步长和多余计数推断问题保留日志，不通过改公式/截点或降低安全门槛凑过。局部导数/短块检查不认证20%路径梯度，原20%符号失败保持；不全AD或训练。近真实NH边界负J双侧设计导数及极大虚域切线未认证，有限采样不能保证处处有效。

- 目标diverse_28中面、L=10mm、t=0.5mm（t/L=5%），仅复用原壳中面，原厚0.328595mm与塑性/摩擦压板不照搬。统一XYZ、宏观横向应变固定，不将其冒充压板试样。
- 连续占据和软孔隙是几何/数值近似，不是异质材料。c不等于恒定壳厚；距离、界面物理宽度和真实参考Gauss点对齐。占据随材料点保持，节点在有限应变中运动。
- 冻结原NH基准：HEX27 N32、65³节点、原Neo-Hookean/界面/η、HRZ质量、显式减步已完成20%。慢路径对壳反力/曲线/功差9.45%/5.87%/6.87%，约10%响应目标通过；快慢速率目标通过；125点检查发现软孔隙采样间翻转，原约10%限于27点离散模型，不能以壁点正常忽略虚域材料有效性。原HEX8反力差22.41%保留为改善前基准，不作活动阻塞。
- 20%中心重新平衡R=3.55e-9、反力2.00447N，伴随线性通过。减薄至0.4975mm的两种Newton校正未过，能量重试方向非下降；候选dFz/dt=-10.84494N/mm未验证。完整0.4975/0.5025mm路径已完成，接受网格与中心完全一致、模式相近。20%保载JVP为+76.093668N/mm，独立差分为-10.797551N/mm，符号不一致；不能用于20%逆设计。旧候选不因新路径相近自动认证；不无限延长失败Newton，不降门槛凑通过。
- 单元改善不证明单一锁定因果；显式有条件稳定，正Gauss体积不证明没有自接触。壳参考自身能量质量未严格通过，周期约束不建立周期镜像接触。稳定性、平衡、可微性和实体精度分别说明。
- 若求路径导数，设计相关占据、质量、仿射惯性、时间推进和目标提取均须进入导数；一致时间离散核对。不把固定状态偏导、有限差分或错误末态伴随称为有效路径AD。共同接受网格路径JVP含HRZ质量与减步半步速度重定位；不包括拒绝/减步控制决策的导数。
- 原约10%前向目标通过保留，约5%是下一轮建议改进目标，非已有精度认证。独立三维参照也需说明其质量；不把更近壳曲线自动当更准确。默认显式仍原NH；客观候选的C²续接版本本轮通过有限前向/域/速率门槛，默认NH保持，经典候选因转动缺陷未采纳；AD软域定位不证明主导前向反力差。
- 不自动加入接触、塑性、稳定化、形态求导或训练。实际机制/失效证据要求时先给范围结论和针对性方案，更新唯一主规划，不从历史README/JSON推导待办。不调厚度、提高η或阻尼拟合参考。
- 用户没有100秒限制，约15分钟主要尝试可接受；旧300秒门槛只解释历史。前向、反向和验证成本分开，保留物理/内存保护，预算停止不叫方法失败；实际阻碍才作最小成本优化。
- 早期轮次和旧薄壁四步按范围冻结。1%/5%厚度梯度、均匀体20%、小网格/已知答案反推不认证当前20%形态、接触或训练。G48/M32/通用N64/中等厚度成本计划等旧停止与条件项不自动继承，不能换c绕过失败。完整历史看文件地图及冻结报告。
- 每项工作说明科研问题、主线作用和证据，区分文献可行性、项目验证和假设，复用结果只补缺口。维护一套FEM内力，不复制求解器或先搭框架；新实验新目录，输入/源码/环境/结果/日志可追溯，冻结原字节不改。归档工具不作活动程序。
