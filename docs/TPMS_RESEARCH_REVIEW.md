# 薄壁TPMS背景有限元：当前进度与可行性判断

更新：2026-10-06。依据正式仓库5b232e7及其冻结证据。本次是文献复核、进度解释和文件整理，没有新增力学求解、Abaqus作业或完整AD。本文是当前综合说明；实际执行仅看[唯一主规划](RESEARCH_PLAN.md)，详细复现见[文件地图](FILE_MAP.md)。

## 1. 我们要实现什么，目前能回答到哪里

研究问题始终是：较薄TPMS能否用体素或固定背景网格在JAX有限元中得到足够可信的压缩响应，并对构型/参数提供有效梯度，最终服务学习、生成和性能驱动逆设计？近期先研究仿真能力，训练后置。连续占据和软孔隙是表示几何的数值近似，不是异质材料研究。

**建议继续，当前前向仿真的可行性已有直接证据；“20%压缩下既准确又有有效设计梯度”的完整目标尚未完成。** 不需要两款软件逐位一致，但必须知道计算的是哪种物理问题、误差指标是什么，以及梯度有没有独立核对。

| --- | --- |
| 代表薄壁、XYZ周期、弹性无接触，计算0至20%响应 | 已完成；最新慢路径对现有壳的反力/曲线/功差6.85%/5.05%/5.98%，必要速率检查通过 |

## 2. 当前算例到底是什么

中面来自用户diverse_28模型，只借用其几何。单胞边长L=10mm，参考壁厚t=0.5mm，因此t/L=5%；中面两侧各延伸t/2。没有沿用原0.328595mm厚度、原塑性或摩擦压板。5%指厚度与边长之比，不是结构相对密度。

基材为均匀可压缩Neo-Hookean超弹性，初始弹性模量E=10MPa、泊松比ν=0.3。这是双方匹配的研究基准，不是已标定的打印材料。当前没有接触、塑性、质量缩放或JAX阻尼。

边界为XYZ三向周期，位移写成 `u(X)=H X+w(X)`，相对面波动w一致；`H=diag(0,0,−a)`，a是宏观压缩比例。20%意味着轴向10mm缩到8mm，宏观横向应变固定为零，内部仍可弯曲。这是周期单胞响应，不是摩擦压板试样；周期方程本身不建立周期镜像接触。

| 符号/名称 | 本文含义 |
| --- | --- |
| φ，占据 | 0至1的几何权重；接近1表示壁，接近0表示孔隙，不是真实多种材料比例 |
| η=10⁻⁴ | 人工孔隙的初始刚度下限比例，不是泊松比或接触参数 |
| F | 局部3×3变形梯度，由节点运动计算，不是反力 |
| J=detF | 当前/参考局部体积比；J≤0表示映射翻转，不能改写成正体积 |
| W、U、KE | 参考体积上的应变能密度、积分储能、动能；KE/U用来判断惯性影响 |
| HEX27 N32 | 每轴32个二次六面体，32³单元、65³=274625节点 |
| 27/125点 | 每单元求解采用27个Gauss点；125点用于同保存位移场的较密检查，不是另一次平衡求解 |
| NH、C² | Neo-Hookean基材；C²表示函数值、一阶和二阶导数连续 |
| AD、JVP、FD | 自动微分、沿一个设计方向传播导数、独立有限差分核对 |

## 3. 固定背景如何计算薄壁

整个立方体都有背景单元，网格不用沿每个孔壁贴体。对每个真实参考Gauss点求距周期中面的距离d，用 `φ=1/(1+exp((d−t/2)/ℓ))` 表示恒厚壁。ℓ=0.05mm/(2ln9)，对应占据10%到90%的界面宽度0.05mm，约为当前壁厚的10%。因此它是光滑距离带，不是精确的尖锐实体，也不是仅用单元中心决定有无材料的二值体素。

占据随参考材料点保持。固定背景指参考连接固定，有限变形时节点仍运动；不能每步在当前空间重新填充材料。积分点没有独立位移自由度：节点位移通过形函数得到F，材料能量给出应力，按参考体积权重积分并组装内力。

当前单元宽0.3125mm，二次节点间距0.15625mm，两者不能混用来声称有几层穿厚度单元；倾斜壁的有效分辨率还与方向和积分点有关。二次位移表示改善弯曲能力，但不自动保证薄壁几何精度。

真实基材的能量为 `W_NH=μ/2·(J^(−2/3) I₁−3)+κ/2·(J−1)²`，其中I₁=ΣF²，μ=E/[2(1+ν)]为剪切模量，κ=E/[3(1−2ν)]为体积模量。应力与切线从同一个能量求导，保持内力、能量和导数一致。[JAX-FEM原论文](https://arxiv.org/abs/2212.00964)提供这种实现基础；其一般固体基准不等于当前薄壁压缩的精度认证。

当前显式时间推进是项目基于共享JAX-FEM材料/内力建立的中央差分、HRZ集中质量、XYZ归并和仿射惯性实现。它绕开了每步全局Newton求解，稳定时间步仍有限。慢加载与保载可接近准静态，需要能量与速率证据，不能仅凭显式算完判断准确。官方[显式动力学示例](https://github.com/deepmodeling/jax-fem/tree/main/applications/explicit_dynamics)是方法参考，不是现成的TPMS验证结论。

## 6. 这次修复的意义与边界

原NH含J^(−2/3)，J≤0时无法按物理NH能量求值。软孔隙即使很软，也可能在薄壁运动中严重畸变；原27点正常不能保证点间正常。上一候选的新125点检查出现6个占据约0.003至0.004的混合尾部翻转点。只忽略它们或对正J子域求和，不能得到模型总能量。

最新方法保持φ、η和物理输入不变。φ≤0.001使用客观虚域能量，φ≥0.01保留原NH，之间平滑混合；只在低占据混合域，把J^(−2/3)在正截点处作值、一阶、二阶导数相接的Taylor续接。截点最大0.1，随占据趋近0.01而趋零。0.1是人工虚域的局部体积尺度，不是宏观10%压缩，也没改真实壁厚。实际F/J未夹断。公式、客观性和数值细节见[本轮冻结报告](VOID_CONTINUATION_PROGRESS.md)。

它的直接贡献是补全混合虚域能量定义，并保持真实壁NH及正J安全区一致性。相对上一客观候选，本轮反力几乎未变，不能把续接本身说成一次新的反力精度跃升。新路径125点检查共409.6万个点，仍有约1.78万个虚域非正J点，约占检查点数0.43%；点数比例不是其能量贡献。它们没有被“修成正体积”，只是人工虚域的材料函数可以求值。未续接NH区φ≥0.01的最小采样J约0.215，当前实体/主要界面采样正常。

这不是负体积真实材料模型，也不是接触律或普遍稳定性证明。靠近φ=0.01且J趋近零时，切线可能很大；不能认证负J跨越真实NH边界的双侧设计导数。最终125点检查也不是全过程、处处有效性的证明。

## 7. 剩余差异为什么不能简单归于单元类型

| 因素 | 已有证据与当前判断 |
| --- | --- |
| 位移表示、弯曲能力 | HEX27改善明确；单元数量、Gauss布局和质量也变化，未证明单一剪切锁定因果 |
| 壳与背景实体近似 | 中面截面运动学、横向剪切、法向应力、曲率/三角面片处理不同，尚未独立分离 |
| 平滑界面与积分 | 总用料相近不代表弯曲厚度矩相同；界面外低占据也会产生贡献 |
| 人工虚域材料 | 新客观处理降低对壳差异并补全求值域，但虚域有人工能量/导数，不是完全消失的空气 |
| 显式时间与质量 | 当前速率差小，宏观惯性主导解释被削弱；JAX与壳惯量、默认数值黏性等并不相同 |
| 参照自身质量 | 壳能量漂移约1.33%未过旧1%门槛，Standard/Explicit终点差约1.92%；工程参照有不确定性 |

上轮保存场新核在27点与125点复积分能量相差约10.04%、内力幅值约2.94%。这是固定同一位移场的采样指示量，不是新平衡曲线误差，也不能拿它直接修正6.85%。当前不因此重开积分/网格扫描。上述差异来源也不能逐项相加构造一个“总误差解释”。

Qiu等直接比较TPMS壳、贴体实体与二值体素，发现薄弱连接仅被一两层体素覆盖时可能明显失真，壳与体素的优势依赖厚度和构型。其删除孔隙体素、弹塑性/接触试样与当前光滑全背景不同，因此支持我们做厚度范围检验，但不能替我们认证结果。[原论文](https://doi.org/10.1016/j.ijmecsci.2023.108657)，本地PDF11–13页已复核。

Hu等的几何投影非线性方法采用虚域/实体能量处理及静力Newton/伴随，说明这类困难有成熟研究基础；其“explicit topology”不是显式动力学。[原论文](https://doi.org/10.1016/j.cma.2024.117636)，本地PDF5–7页。Han等2026年比较研究进一步指出，有限应变下不同虚域插值会改变敏感性，数值稳定不等于物理和导数一致。本轮只借鉴这个诊断观点，不切换到其框架或宣称当前续接已获文献认证。[原论文](https://link.springer.com/article/10.1007/s00158-026-04332-8)，§3.2.1、§3.3及结论。

## 8. 梯度优势保留到什么程度

理论上，JAX可以对材料、占据、质量、时间推进和目标提取求导。隐式平衡可用伴随，离散时间路径可用JVP/VJP；高维设计不必对每个参数分别完整差分，这是未来逆设计的重要优势。它不保证单参数更便宜，也不使屈曲分支、最近面片选择或接触自动光滑。

| 原NH路径厚度导数 | JVP，N/mm | 独立完整路径差分，N/mm | 结论 |
| --- | ---: | ---: | --- |
| 10%压缩反力 | −10.648858 | −10.648356 | 核对差约0.0047%，通过 |
| 15%压缩反力 | −11.656391 | −11.655845 | 核对差约0.0047%，通过 |
| 20%保载平均反力 | +76.093668 | −10.797551 | 符号相反，未过 |

导数表示厚度每增加1mm时的局部反力变化率，实际差分扰动仅±0.0025mm；这里的导数差不是前向力误差。原完整JVP主体约49.77分钟，高维反向成本未验证。20%变形敏感性集中在虚域，提示人工域/路径变分响应问题，但尚未证明唯一机制；不能据此断言JAX的AD算法出错。

最新核的局部导数和短块传播通过，说明可微接口保留，没有用不可导裁剪掩盖失效。但新核的完整20%导数尚未求解核对；旧10%/15%结论也不能直接移植到新能量。未来总导数必须包含占据、HRZ质量、仿射惯性、时间推进和响应提取，并与一致接受时间网格独立验证；当前固定网格路径导数不含拒绝/减步决策导数。

周期非线性目标曲线与AD/伴随逆设计已有先例，但Thillaithevan等采用二维平面应变、修改SVK和静力求解，不能替代三维薄壁显式认证。[原论文](https://doi.org/10.1007/s00158-024-03761-7)，本地PDF4/5/7/8页。

当前厚度导数是在固定距离数组上求得，中面最近三角形预处理尚未形成有效形态AD。未来“构型/参数→几何占据→FEM响应→损失”的整条链都需要可用导数，不能从厚度导数直接跳到任意生成形态端到端可微。Style-Constrained扩散论文提供几何先验与可微物理引导的长期动机，不是当前20%求解器认证。[作者预印本](https://arxiv.org/abs/2601.06469)。训练后置合理，但它也不必然轻松或免费。

## 9. 下一步为什么这样安排

第3步匹配0.45/0.55mm已完成，0.50mm复用；两点均通过原前向门槛，三个采样厚度最大反力/曲线/功差8.28%/7.48%/7.31%。 方法、峰值/模式、材料与参照质量的逐项说明见[厚度执行报告](THICKNESS_RANGE_PROGRESS.md)。

本次已补“同一固定方法是否只在这一个厚度有效”。执行时维持原中面、网格、本构、边界和候选常数，新增0.45/0.55mm匹配壳工况；0.50mm复用。±10%厚度变化是物理范围验证，不是调厚度拟合原曲线，也不是精确导数检验。

如果新增两点的反力/曲线/功均保持既定约10%目标，且材料域、能量和惯性检查正常，则“同中面附近厚度范围的前向替代”依据明显增强。若某点失败，应围绕那个机制给范围结论，不连做参数扫描凑通过。厚度检验仍不证明跨形态、全部局部应力或真正接触压溃。

这轮范围明确后再规划新核完整梯度的最小验证，不能无限延长失败AD。若前向可信而目标20%梯度仍不可用，可继续作为前向研究工具，同时缩小梯度适用范围；如果最终研究明确依赖20%梯度引导，就必须把这个缺口作为决定是否调整路线的关口。当前尚无充分证据要求换方向，但也没有依据保证完整终点必定成功。

曲面参数、构型和本构都可继续研究：先用一个已有匹配中面的几何变化检验迁移，再按实际需要扩大材料范围。c与真实壁厚需分开；仅改变E可能主要缩放力级，ν或能量形式改变更能检验新机制，但也需要重新验证匹配本构及虚域处理。它们是下一阶段的候选，不是本轮扫描任务；换构型前向成功不等于形态梯度认证。
