# 机制审查：初始占据影响与大压缩峰位须分别解释

更新2026-10-09，r46只读复盘。当前数值范围见[状态](RESEARCH_STATUS.md)，逐轮事实在冻结报告，后续唯一执行计划见[规划](RESEARCH_PLAN.md)。本页集中解释，避免导航/状态重复铺开全部细节。

## 当前判断

**占据过渡是初始刚度的可测因素，大压缩尚需解释失稳路径。** 两构型同部分密积分下，取消过渡均使初始K下降约2%，相容位移重新平衡是主要组成之一。但diverse_04二值N32完整20%仍晚降载，N64部分路径也尚未捕获峰。因此，不能用统一5%刚度校正解决全部非线性差异。

本次不能宣称“N64更不准确”或“网格已解决问题”。旧N32 T4ms完整20%，新N64 T1ms只有13.59%；共同0–10% RMS/自身壳峰为0.80%/1.90%，共同0–13.59%为22.12%/4.85%。前者略变大，后者减小，且各自壳的降载阶段不同。N64末端35.39%是同压缩量点差，N32的25.50%是峰力差，不能互作排名。原完整曲线/功/保载目标未通过保持。细节与新图见[r46](../validation/binary_mesh_reassessment_20261009_r46/REVIEW.md)。

## 初始问题已经排开哪些因素

r30/r41初始诊断是0.01%宏观压缩、L10mm对应0.001mm位移，K为反力幅值/位移幅值、单位N/mm；静态平衡不含质量、加载时间与阻尼。diverse_04平滑K=4.916455、壳4.651219N/mm；diverse_28平滑3.888256、壳3.774884N/mm。它们支持初始偏差真实存在于当前离散/模型比较，不能归因为显式惯性。

生产占据为`φ_s=1/[1+exp((d−t/2)/ℓ)]`，t0.5mm、ℓ=0.05mm/(2ln9)；s=η+(1−η)φ、η1e−4。二值`φ_b=1[d≤0.25mm]`只改变参考Gauss材料权重，仍有软孔隙，不删单元。壁内恢复权重与壁外去尾同时发生，φ附着参考材料点，不按当前空间重新分类。硬阈值几何AD通常为零/不连续，未替换可导生产表示。

12³为每个选中单元每轴12点；两构型的区域分别冻结，没有照搬。局部8/12关口通过，选区外未密检查；剩余差不是全域充分积分后的真实实体/壳差。最接近壳的原27点数字可能含采样误差抵消。增加积分点不增加位移自由度，增加N也同时改变几何采样与质量，不能保证对壳误差单调下降。

## 能量账目说明位移协调很重要

设q_s/q_b是同一周期位移空间内的平滑/二值平衡，初始U是占据权重乘线弹性能的积分，则

`U_b(q_b)−U_s(q_s)=[U_b(q_s)−U_s(q_s)]−[U_b(q_s)−U_b(q_b)]`。

第一项固定原平滑位移只换权重；第二项是相容重新平衡释放。diverse_04同部分密积分以平滑全能量为分母，两项−0.6217%与释放1.4988%，合计−2.1205%；diverse_28对应−0.6929%与释放1.6506%，合计−2.3435%。同微小位移下U=½Kδ²，因此最后一项也对应K变化。

这些数字不是壳误差的唯一分摊；分解依赖从哪一个保存位移出发。它们确认仅看总材料量/直接过渡储能会遗漏重新分布，但尚未定位具体连接、桥接或锁死。完整恒等式、局部积分及原中断见[r40–r41](../validation/binary_occupancy_20261008_r40/REVIEW.md)、[r43](../validation/binary_diverse28_20261008_r43/REVIEW.md)及正式r42记录。

## 大压缩需要另看动态路径和壳—实体差别

r44二值N32完整20%在初始接近后仍至15.2387%出现加载峰，壳为11.8241%；全曲线/功/保载均力差35.90%/40.21%/47.89%。若只是所有静态弹性能同乘一个常数，平衡位移与切线零点不会因该常数改变；占据的局部改变、质量和动态分支不属于这种统一缩放。所以约5%初始偏硬不是全部峰错位的充分解释。

r45 T1ms的1%反力瞬时惯性贡献约0.12268N，旧T4ms为0.00712N；时长缩短改变了动力强度。内部宏观力依然来自当前动力位移，不能冒称无惯性平衡曲线。末端该贡献只有−0.04691N，而壳/背景差1.60061N，不能仅扣掉输出惯性项解决；此前动力作用和分支选择仍可能重要。末态低KE不等于全过程准静态。

[Abaqus显式说明](https://docs.software.vt.edu/abaqusv2025/English/SIMACAEANLRefMap/simaanl-c-expdynamic.htm)解释加载加速会改变惯性及预测响应；[Liu等延迟分岔](https://arxiv.org/abs/2010.07850)说明纯弹性跳跃也可依赖速率，不能直接套其拱模型给TPMS峰位公式。壳已有T4/T1/T0.25ms峰11.82%/12.79%/5.47%，说明本项目速率效应不能用简单单调规则概括。

S3R的中面、转角、厚度应力假定和三维HEX27不同；允许横向剪切，并非简单“没有法向变形”。[官方壳说明](https://docs.software.vt.edu/abaqusv2025/English/SIMACAEELMRefMap/simaelm-c-shellelem.htm)支持区分运动学。当前同材料参数不构成完全相同离散问题，壳仍有默认体积黏性与人工能量限制。不能只因背景不贴壳就认定JAX内力核错误，也不能因此忽略差异。
