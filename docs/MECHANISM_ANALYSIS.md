# 初始约5%偏硬：研究复盘、理论依据与判别方向

更新：2026-10-08。本次完成r36–r38。综合既有文献与新干预后，最值得继续区分的是**固定背景位移近似限制**与**有限厚度三维实体和壳的模型差别**。当前尚未找出5.7025%的唯一来源；下面的原因排序是研究判断，不是已认证结论。

## 为什么值得继续，但应换成更有区分力的试验

我们要建立可导的薄壁TPMS计算能力，而不只是画出一条像Abaqus的曲线。diverse_28三个厚度到20%的有限范围一致性说明路线有实际基础；diverse_04的峰错位和计算中断说明泛化边界还没有建立。当前5.70%的无惯性初始偏差，是短、可解释、能把时间算法暂时移开的切入点。它是值得追查的基础偏差，但不能提前称为大压缩全部误差的主要原因。

在相同几何、本构和静态位移边界下，若只是把所有刚度统一乘c，则平衡残差也乘c，平衡位移不变；切线的零特征值位置也不因这个常数改变。反力幅值缩放，不等于失稳压缩量移动。动力学、局部刚度重分配和非线性分支不服从这个简化推导。因此不能用5.7%反力倍率修正来宣称解决4个百分点的动态峰错位。

r35主体的法向/剪切残差能是在选区、原Gauss点、给定位移下分解的量。它们不对应各点可以独立实现的位移松弛，不能直接扣掉整体差异。S3R本身允许横向剪切，不能删掉实体所有剪切去拟合壳。深虚域直接储能小，也不证明其对平衡位移的耦合为零。

## 新干预给出的限制

r36原规划的一个兼容法向模式在同积分固定节点下仅释放0.0023715%全能，未达预定0.5%相关性关口，因此不继续该模式全局平衡；这不排除跨胞或其他位移限制。

r37界面宽0.025/0.05/0.10mm原27点对壳差4.1304%/5.7025%/7.6700%，证明该数值表示有影响；但窄界面选区复积分变化更大。r38一次相同部分密积分确认，宽度减半仅使K降低0.9120%，对壳仍5.5301%。它没有认证全部5%来源，也不是全域锐界面收敛。不继续扫陡峭度或按最接近壳挑参数。公式、检查、分母及两图见[本轮报告](../validation/interface_width_mixed_20261008_r38/REVIEW.md)。

## 仍保留：位移场自由度是否够用

背景单元边长0.3125mm，0.5mm壁厚名义跨1.6个单元；二次节点间距0.15625mm不是单元边长。局部曲面法向随位置变化，穿厚度收缩和切向应变可能需要与曲率相关的三维变化。更准确地采到材料只改积分，不增加位移自由度，因而“增加积分点仍偏硬”并不否定位移近似问题。

[有限胞综述](https://arxiv.org/abs/1807.01285)把高阶近似和几何积分列为不同组成；[Shell Finite Cell Method](https://doi.org/10.1016/j.cma.2011.06.005)专门讨论薄壁相对笛卡尔胞过细时的困难，并采用面参数域与几何映射。这支持检查当前薄壁近似的思路，不表示我们的Q2平滑场等价于完整FCM或需要立即换框架。

[高阶实体/壳研究](https://doi.org/10.1016/j.cma.2004.07.042)区分通过厚度方向近似改善离散误差与控制壳理论模型误差。本文实际读取出版商摘要/引言片段，未取得全文，不继承其算例精度。当前ν=0.3也不是接近不可压缩，不能仅见偏硬就命名为体积锁死；当前初始又以膜内承载为主，不能凭空套用“剪切锁死”。

需要一个**同材料、同几何、同积分，仅增加可兼容位移**的干预。固定节点局部翘曲试探有价值：它可以证明原场附近确实存在可实现的能量下降，而不必重建复杂体网格。但一个模式只能回答一个有限问题；没有下降不证明原位移空间已经充分。

## 第二优先：三维有限厚度与壳不一定解同一个问题

Abaqus官方说明，[S3/S3R是允许横向剪切的通用壳](https://docs.software.vt.edu/abaqusv2025/English/SIMACAEELMRefMap/simaelm-c-shellelem.htm)，常规壳厚度方向采用零正应力等截面假定。三维实体则在完整三维运动学和本构下平衡，厚度方向应力由解决定。E、ν、厚度和宏观边界相同，不等于局部连续问题完全相同。

t/L=5%只能说明全局厚度比例，不能单独保证每个承载局部都是薄壳极限。局部曲率尺度、连接区域、截面方向和边界层可能影响实体/壳差别。r32的面法向变化量只是离散代理，不是主曲率，不应用它反推可靠t/R或宣布壳失效。S3R人工能量很小降低了明显人工刚度问题的优先级，仍不认证所有壳离散和模型误差为零。

因此，如果兼容试探不支持现有改进，下一项应先设计一个简单曲面三维/壳/背景补片，以清楚的共同几何和边界区分两层误差；不再把复杂TPMS贴体网格变成前置阻塞。若真实三维本就更硬，目标应是可信三维响应和有界的壳差异，而不是消除所有壳差别。

## 仍保留但暂不领先的因素

**距离带与截面表示。** sigmoid将几何界面替换为窄过渡带，三角片最近距离在棱边处并非光滑法向偏置。总体材料加权体积仅低0.3202%，并不证明高能区的有效截面和运动学一致。r35中层原面片归属稳定，降低了“中层全部由最近片切换污染”的优先级；外层两侧仍有面片归属变化，不能一概排除几何表示。

**人工软域耦合。** 小η抑制直接储能，却仍参与连续位移平衡、数值条件和后期稳定步长。r25近零填料在8.35%之前近乎与壳重合，仅削弱该早期特定填料影响；尚未覆盖峰，也非当前C²背景的等价模型。当前不按接近壳来挑η或阻尼。

**参照与周期约束。** 壳有转角自由度，背景只有平移；需要检查对应运动学，不应立即换压缩边界。现有PBC/功平衡通过降低实现差错优先级，并没有使两种模型完全一致。加载速率、集中质量和后期接触属于后续峰/大压缩问题，不能解释已经无惯性的零态差异。

## 本地论文复核给出的正面与负面信息

Qiu等[TPMS实验与五类网格比较](https://doi.org/10.1016/j.ijmecsci.2023.108657)的PDF11–13页表明，薄弱连接只有一两层二值体素时可能丢失特征、偏软；某些较厚构型体素表现较好，壳在致密化阶段也有局限。该文的二值、塑性/接触、多单胞与本项目不同，不能把其误差量复制到当前模型，也不能据此判定“1.6层必然偏硬”。

Hu等[几何投影有限变形优化](https://doi.org/10.1016/j.cma.2024.117636)PDF5–7页支持固定网格、平滑材料描述、虚域能量处理和伴随敏感性的理论基础，但其静力Newton与投影公式并非我们C²显式路径的认证。它证明方法家族有依据，没有直接给出本项目5%差异的答案。

Wang等[2025体素建模预印本](https://arxiv.org/abs/2506.04028)本地PDF1–3页研究的是网格几何质量与尺寸联合控制；其中minimum Jacobian不是我们有限变形过程中detF的安全门槛，不能把0.3直接移植到本项目。

另外，[Trace-Finite-Cell壳方法](https://link.springer.com/article/10.1007/s00466-020-01956-5)在背景网格上对隐式曲面建立薄壳分析，说明“固定背景网格”不必等同“三维软填充实体”。但文中是线性Koiter/C¹样条方法，需要独立壳、曲面积分和导数验证；它只作为长期备选，不构成本轮改写求解器的理由。

## 已执行兼容试探的理论条件

设ξ为单元[0,1]³坐标，原场u₀满足周期约束。单元模式ψ须在整个边界和原27节点为零，新增场u=u₀+αψ，因此不改变邻接面连续性及原PBC。对于固定几何的初始正定三维弹性能，定义

`U(α)=U₀+αg+½α²k，g=∫ε(ψ):C:ε(u₀)dV，k=∫ε(ψ):C:ε(ψ)dV>0。`

最小化得α*=−g/k、可实现释放ΔU=g²/(2k)。这里C包含原占据/η权重，δU与位移相容，而非直接把每个Gauss点改成平面应力。多个边界为零的独立单元模式可局部计算，但节点固定释放并不等于新全局K；全局再平衡还需求解。

本次特别修正判别设计：应以r34同一密积分诊断为基线，不能同时改积分与位移。新增模式不在原Q2空间，27点对其能量不自动充分；先用已有8/12规则核查同模式g、k及释放。方向和模式必须预先给定，不能从壳曲线反选。具体模式和无退化规则已在r36启动前冻结并执行；8/12级聚合核查通过，但释放过小，已进入原规划的简单曲面判别设计分支。

## 可行性评价与收口原则

**值得继续，但“普遍替代Abaqus至20%并有正确梯度”尚未证明。** 当前失败不能直接归咎于JAX自动微分或平台；相同离散问题的早期基准、膜向解析和部分大压缩前向支持实现基础，难点集中于薄壁几何/位移表示、软域大畸变及失稳路径。

较小初始误差是积极证据，不是后期可行性的保证。即使这三步将初始误差缩小，仍需另行解决diverse_04峰位/时间步，以及新能量完整路径导数。反过来，若清楚地证明一部分差异来自真实三维与壳的差别，应接受有依据的适用范围，避免无止境追求壳曲线重合。下一步先完成简单曲面可比性设计，只执行[唯一三步规划](RESEARCH_PLAN.md)，不扩展训练、接触或通用框架。
