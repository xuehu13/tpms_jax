# 薄壁20%误差定位：第1步结果与三维参照准备

2026-10-06。长期问题仍是：薄壁TPMS能否用JAX背景有限元可信地计算压缩，并在以后保留有效梯度用于构型/参数逆设计？本轮执行[唯一近期规划](RESEARCH_PLAN.md)的第1步，并启动第2步。没有重算已有完整前向、没有重试20%完整AD、没有训练或新增Abaqus作业。原求解器、材料和已冻结结果未改。

**当前结论：剩余差异尚不能归因于一个因素。数值结果提取没有发现错误；界面平滑、软域和局部面片几何各有可测影响，但不能直接相加解释9.45%的反力差。独立三维实体参照仍有必要。其恒厚边界已生成，体积网格尚未通过，不能宣布三方验证完成。**

## 1. 此次做了什么，为什么做

本轮没有继续遍历网格、厚度、边界或加载速度。旧快慢速率核对已经通过，原HEX8到HEX27的改善也已保留。新增工作只补尚缺的判断：

1. 用既有四条曲线，分开查看起始段、峰值附近和峰后下降段。
2. 从HEX27快/慢保存自由度，按实际安装的基函数重建全部884736个Gauss点的变形梯度、应力和储能，核对原内部宏观力。
3. 区分实体、界面、软域的同状态贡献；诊断96个面积分层取样位置，以及此前已标记的3处面片棱角位置的膜厚积分和弯曲厚度矩。
4. 从原中面距离生成尖锐恒厚边界，处理单胞裁剪和相对面配对；进行有限次数体积网格尝试，记录未通过的具体原因。

第1步主体18.18秒；这只是后处理时间，不是新的20%求解时间。文献可行性、项目已验证结果和当前假设仍分别说明。

## 2. 两个模型哪些相同，哪些不同

| 项目 | JAX背景实体与Abaqus壳的关系 |
| --- | --- |
| 中面、单胞、目标厚度 | 同diverse_28中面，L=10mm，t=0.5mm；未沿用原0.328595mm |
| 实体材料 | 同可压缩Neo-Hookean，E=10MPa、泊松比0.3；剪切模量3.84615MPa、体积模量8.33333MPa |
| 宏观压缩 | XYZ周期、横向宏观应变0、压缩至20%、无塑性/接触；不是摩擦压板试样 |
| 厚度表示 | JAX用周期距离的光滑占据和软孔隙；壳用中面加截面厚度 |
| 自由度和单元 | JAX为HEX27三维位移；壳为S3R位移/转角，厚度5点Simpson积分；它们不是同一离散问题 |
| 孔隙 | JAX有η=1e-4的软域，壳没有对应体积单元；不称为异质材料 |
| 数值动力学 | 两者显式；JAX为HRZ集中质量与减步中央差分，Abaqus采用其自身质量/稳定步和默认数值黏性 |
| 速率 | JAX快/慢加载0.004/0.008秒；慢壳0.04秒。秒数不同，是否准静态由实际能量和速率响应判断 |
| 反力口径 | 位移共轭的宏观力，JAX内部力与含惯性力分别保存；接受比较沿用原保载后半段平均，不能混用单个末帧 |

壳采用平面应力等壳运动学，三维实体允许厚度方向变形和应力，几何棱角表示也不同。即使材料常数相同，壳/实体仍可能有物理近似差别。Abaqus的C3D20也不能称为JAX的HEX27。

## 3. 差异何时增长

| 曲线特征 | JAX慢HEX27 | 慢Abaqus壳 | 解释 |
| --- | ---: | ---: | --- |
| 0.2%至1%压缩拟合刚度，N/mm | 3.8876 | 3.7187 | 约4.54%偏硬；这是动态曲线的小区间拟合，不替代原静力初筛 |
| 峰值反力幅值，N | 2.3973 | 2.2431 | 约6.87%差异 |
| 峰值对应压缩 | 10.80% | 10.55% | 主要峰值位置接近 |
| 原口径20%保载反力幅值，N | 2.004589 | 1.831447 | 原9.45%差异保留 |

“刚度”在这里是力除以宏观位移的斜率，压缩1%对应0.1mm。0至5%区间平均多出的力约0.0378N，5%至12%约0.1294N，12%至20%约0.1657N：差异从开始就存在，峰后进一步增长，而不是只在最后一个点突然出现。

本轮400个共同压缩采样点的诊断RMS/原Standard峰值为5.8722%，与原冻结口径5.8727%一致到显示精度。该指标是整段力差的均方根，分母固定2.258914N，不是每个点都差5.87%。新诊断不替换旧接受指标。原输入功差6.87%亦保留。

快慢JAX原反力/曲线/功差约0.057%/0.607%/0.0059%；壳Standard与慢Explicit终点相差约1.92%。这些证据降低“加载速度是剩余差异的主要原因”的优先级，但不证明所有局部振动为零。壳自身约1.33%的全局能量漂移仍未过原1%质量门槛，因此不能当精确真值。

## 4. 保存场、软孔隙和界面给出了什么证据

使用参考坐标X，实际变形梯度F=I+H+∇w，J=detF为局部体积比。H是给定宏观压缩，w为周期位移波动。JAX实体能量W由共享Neo-Hookean定义；P=∂W/∂F是第一类Piola应力。宏观内部力为参考体积上Pzz积分再乘L²，储能为W积分再乘L³。

这里φ是占据，s=η+(1−η)φ是能量和应力倍率。积分权重用原真实Gauss权重。独立解析应力恢复与共享JAX材料核抽样核对，绝对误差约1e-13MPa；重建整体内部力和能量相对原记录约1e-14和1e-15。没有发现单位、占据、参考积分权重或内部宏观力提取不一致。

以下取慢路径最后保存状态；其内部宏观力−2.004675N与保载平均−2.004589N是不同口径。正负贡献可抵消，因此表中是净力份额。

| 同状态区域定义 | 净内部力份额 | 储能份额 | 最小J |
| --- | ---: | ---: | ---: |
| 软域：φ<0.01 | 2.146% | 3.559% | 0.03538 |
| 界面：0.01≤φ<0.9 | 11.173% | 18.706% | 0.58395 |
| 实体：φ≥0.9 | 86.680% | 77.735% | 0.84513 |

按另一种严格代数分解，把整个单胞中的统一η底座单列，得到内部力−0.040392N，占2.015%，储能占3.212%。这是“整个η底座”，不是“仅软域”，两者不能重复相加。

判断：软孔隙已产生可测响应，也确实发生大局部畸变；界面有不可忽视的储能。**同状态分解不等于因果误差分解**：删除软域后结构会重新平衡，界面项又包含真实薄壁材料的一部分，不能把这些力直接从总力里扣掉，宣称误差已改善。正J也不是没有自接触的证明。

已有20%导数放大主要位于软域的证据继续保留；本轮没有把它当作主导前向9.45%差异的证据，也没有继续重跑完整AD。

## 5. 厚度是否被平滑“加厚”

φ=sigmoid((t/2−d)/ℓ)，d为周期中面距离。当前单侧界面的10%至90%宽度0.05mm，对应ℓ=0.011378mm。不能把这个界面宽度直接加在0.5mm上，当成壳厚。

用局部法向坐标z，M0=∫φ dz反映膜向用料厚度，M2=∫φ z² dz反映小变形弯曲时的厚度权重；实际弯曲还受泊松比、曲率、位移场和积分影响。若剖面不对称，先扣除剖面质心偏移后计算M2。

对于理想平壁，当前t远大于ℓ，M0约t，M2约`t³/12+π²ℓ²t/3`。一维数值积分核对得到膜厚比约1.0000，弯曲厚度矩比约1.02044：**平滑基本不增加膜向用料，却会把材料稍向外摊开，使理想弯曲厚度权重增加约2.04%。这不是整个TPMS反力增加2.04%的预测。**

96个面积分层位置呈现这一典型行为；它们不是面片角点的全覆盖。此前标记的3处邻面夹角约15°位置另作定点诊断：距离带沿当前面片法线的宽度约0.50527至0.50606mm，比名义厚度多1.05%至1.21%；连同平滑后的局部弯曲矩相对名义平壁多5.34%至5.83%。这是距离到相邻面片的棱角效应，不能推广为全结构加厚。

全体原Gauss点上，平滑与同点二值体积为151.6338和151.5386mm³，相差约0.0628%；全局距离平方矩相差约2.25%。全局矩还包含曲率和表面积变化，不能叫精确弯曲刚度。用料相近并不能排除弯曲和界面离散误差；本轮也未拿二值同点场重新求解。

| 优先级降低 | 加载速率、总体模式切换、明显材料/单位/结果提取错误 | 原速率及模式证据、此次恢复核对均不支持其为主要解释；不是普遍排除 |

下一项假设具有区分性：同中面尖锐恒厚三维实体在相同物理条件下，是否仍系统比壳偏硬？若是，壳/三维表示差别值得进一步解释；若实体更接近壳，背景跨界面表示和虚域的优先级提高。独立实体自身若质量不足，两种判断都不能成立。

因此现在不急于启用能量插值，更不因能量候选可能修复AD就假设它能消除前向反力差。原约10%前向目标通过保持，约5%仍为待实现目标。

## 7. 第2步已经推进到哪里

以原三角中面的周期距离d=0.25mm构造尖锐边界，用80个采样间隔的四面体等值面几何并裁剪到10mm单胞，六个平面盖面使用相同对角剖分。这里的采样格只用来生成贴体实体边界，不是再做一套二值背景力学计算。

得到178898个边界节点、357812个三角面，闭合边每条被两面使用，相对面节点集合未匹配数均为0，边界包围体积151.6880mm³。表面三角面质心的真实距离偏差：1%至99%分位约−0.00331至+0.00410mm，极值−0.00930至+0.01150mm。它仍是几何近似；闭合和配对不证明所有体积/接触/网格质量合格。

体积网格未完成的原因明确如下：

| 尝试 | 实际结果 | 处理 |
| --- | --- | --- |
| Gmsh分类、重新参数化后配周期网格 | 同一两三角片反复分割至18000级以上，无进展 | 人工终止本次进程，保留完整日志与源码 |
| 保留匹配边界直接四面体化 | 极差单元，日志最低质量约5.7e-8；Netgen优化反复报告数千非法四面体，最终进程段错误 | 未提交Abaqus；没有可接受二次体网格 |
| 一次0.003mm邻点焊接清理 | 相对面仍配对，最大位移0.00454mm，但闭合流形检查失败且极薄三角片仍存在 | 拒绝清理结果，没有拿它继续计算 |

这些是本次自动网格路线的实际阻碍，**不是JAX前向失败，也不是三维参照理论上不可建立**。未改变厚度、η或材料来绕过问题。Gmsh区分离散曲面重新参数化与体积剖分，周期功能要求实体的相对面实际匹配；重新参数化不是恒厚薄壁网格质量保证。[Gmsh官方手册](https://gmsh.info/doc/texinfo/)。

可信薄壁参照仍计划使用质量合格的二次四面体或分层体积网格，避免单层线性C3D4带来新的偏硬。Abaqus官方资料建议四面体采用C3D10/C3D10M，并说明Explicit中C3D10通常优于C3D10M；最终结合实际网格和2026运行选择。[Abaqus实体单元资料](https://docs.software.vt.edu/abaqusv2025/English/SIMACAEELMRefMap/simaelm-c-solidcont.htm)。

继续仍停留在主规划第2步：最低限度替代是保持闭合拓扑和周期一致的短边折叠/边界重整，替代失败的无拓扑保护邻点焊接；先对一个盖面及相连局部检查，再允许一次完整体网格。若这一局部修复不能满足几何、拓扑与质量要求，先明确三维参照未建立，选择范围更小的分层三维弯曲/局部壁面参照，不无限扩大网格平台，也不宣称它代替整个TPMS20%参照。第3步的改进和5%比较暂不越过这一关。
