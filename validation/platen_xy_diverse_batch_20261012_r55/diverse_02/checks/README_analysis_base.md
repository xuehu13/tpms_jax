## 建模条件与可比性

复用原diverse_02的13752节点／25930三角中面，在自身实际N32积分点生成占据场，不拟合几何或体积分数。L10 mm、t0.5 mm、NH E10 MPa／ν0.3／密度1e−9 tonne/mm³。JAX仍为HEX27／27点、HRZ、η1e−4、界面0.05 mm、objective_void/C²；Abaqus为同中面的S3R壳、截面5点。两端物理加载时长均4 ms、保载0.2 ms，五次平滑下压2 mm。

仅XY周期，宏观横向伸缩自由、宏观剪切零，没有Z周期或壁节点额外固定。584条独立节点关系形成3504条壳方程；上下端分别[225, 225]个中面节点接触压板。JAX把自身连续占据端面面积聚合到同一批端缘位置，面积守恒、Q2插值、kn320 MPa/mm；Abaqus端缘节点接触忽略接触厚度，截面厚度仍保留。两端运动学、罚律、接触插值和惯性离散不同；不是同离散问题。

没有全壁面、自接触或周期镜像接触。实际F/J不夹断，主体正J保护及软域能量保留。允许物理跳跃与动能升高；数值失败、步长缩小和能量失衡另行报告。对照只回答共同简化加载下的计算能力，不认证真实完整有限厚度接触。
