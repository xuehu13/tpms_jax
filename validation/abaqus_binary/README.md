## 数值定义

- L=1，实体域为 |G(x,y,z)|≤0.541062。先把背景四面体与两个等值面相交，再生成封闭三角边界及体网格；孔隙没有单元，也没有 E_min。边界是解析域的分片线性逼近。阈值 c 不是常数物理壁厚。
- Gmsh 仅重划体网格，检查前后体积不变、边界闭合、正 Jacobian 和相对面三角剖分一致；C3D10 的中边节点取直线中点，保持同一个分片线性几何。R=1 在同一几何上细分四面体，分离 FE 加密与几何加密。
- 实体材料 E_s=10、ν=0.3，线弹性、小应变、NLGEOM=NO。c 沿用原模型标定值。独立 8 次扰乱 Sobol、每次 2^21 点得到解析二值体积分数 0.350475907，均值标准误约 1.58e-05；它并非严格 0.350000，采样标准误也不是确定性误差界。
- 采用与 M4 相同的 XY 周期边界、底面 u_z=0、顶面 u_z=−0.01，顶底的 u_x/u_y 自由。QX/QY 固定为零或自由无外力；QZ 控制压缩，角点固定两个横向平移。该边界给出本工况的表观轴向响应；全 XYZ 周期、接触压板或非线性压缩属于不同问题。
- M4 的投影定义是 ρ=sigmoid[β(G+c)]−sigmoid[β(G−c)]，E_q=E_s[e_min+(1−e_min)ρ_q]，ν 固定为 0.3。ρ 是刚度插值用的代理场，∫ρ/V 是投影体积分数；它与二值实体体积分别定义。N32、β20 的 ∫ρ/V=0.350688391。对照采用线性 E(ρ)，没有引入更高次 SIMP 幂。
- 裁剪立方体内有主体和两块角部实体；施加 XY 周期匹配后连通分量为 1。逐节点建立总位移跳跃约束，包含 C3D10 中边节点；检查被消元自由度唯一、没有边界条件冲突或后续引用。
- 宏观应力为 ∫_solid σ dV / V_gross，V_gross=1。另列 ∫σ dV / V_solid 的实体平均应力，避免把两者混用。

## 验收证据与限制

每个 ODB 读取最后完成帧、全部物理节点 U/RF，以及每个 C3D10 的四个积分点 S/E/IVOL 和全模型 ALLSE。核查输入/网格 SHA256、积分点匹配、有限数值、正积分体积、几何体积、控制反力与宏观应力、顶底反力平衡、周期跳跃和加载面位移；能量同时比较积分 S:E、ALLSE、0.5 RF·U、0.5 V_gross σ_macro:ε_macro。响应/能量相对阈值 1e-6，位移绝对阈值 1e-8。Abaqus E 的剪切分量是工程剪切，六分量 S·E 不再额外乘 2。

均匀 C3D10 固定/自由基准分别还验证解析应力、解析能量和全节点仿射位移。二值实体使用原生积分点输出，与上一阶段线性用户单元重建能量的证据类型不同。

所有归档作业无求解错误、数值奇异警告或负特征值警告。畸变单元警告仍存在，数量及原文保存在 diagnostics、DAT 摘录和原始 MSG 中；完整 DAT 在本机作业目录，哈希及大小已记录。部分细网格单元质量很低，不能把通过全局反力筛查写成局部应力收敛或高质量网格认证。G48 和 G24R1 细网格使用 8 GB 内存限制，存在已核查的线程求解器转外存混合直接求解提示；计算完成后仍须逐项验收，不依据 bat 退出码判断成功。

共享交点采用原始边端点的统一顺序计算，修复 G48 的浮点去重拓扑异常并加入局部回归测试。体网格如出现完全重复的四面体，只合并相同连接关系，随后重新检查流形、周期匹配与体积。没有删去小实体碎片或小体积单元。

下一步改善表面/体网格质量并核查局部应力；随后再讨论匹配体积分数的模型研究或全 XYZ 周期均匀化。原生 C3D8+USDFLD 仍是另一条离散算子路径，编译器和场映射尚未验证，当前结果不声称它已完成。
