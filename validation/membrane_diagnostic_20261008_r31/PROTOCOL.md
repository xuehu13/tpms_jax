# r31：一个膜向试片，检验厚度法向松弛机制

启动依据：r30无惯性初始刚度偏高5.7025%；同状态深虚域能量0.6807%，φ≥0.01处点态法向及横向剪切松弛能量分别0.5818%、2.0185%。这些不是因果贡献，不能直接修正TPMS，也未证明唯一主因。

只做一个膜向平直试片。复用r27已存在的L10×B1.25×背景高2.5 mm网格，HEX27、N=(32,4,8)、边长0.3125 mm、27点；薄壁厚0.5 mm、中面z=1.25 mm，同η=1e-4、0.05 mm界面和objective_void初始共享切线。以原中心相位为唯一相位，不增加相位/网格扫参。原弯曲试片不重算。

x端面规定ux=0及0.001 mm，uy全场为0（膜面另一方向应变0），uz自由、只固定一个厚度位移去除平移。这是解析膜向补片试验，不是改变TPMS三向周期条件。解析为厚度平面应力：εzz=-ν/(1-ν)εxx，轴向膜模量E/(1-ν²)。以实际同高斯场积分的截面积求离散解析刚度，另报同连续场密积分及真正厚0.5 mm板的解析值，严格区分积分误差与有限元运动学误差。

一次稀疏线性解，900秒预算；真实自由残差≤1e-8、反力半功及同高斯解析刚度相对差≤1e-8，法向泊松收缩相对差≤1e-6、本构初始切线绝对差<1e-11，有限值。不自动追加计算、拟合E/t/η/阻尼或另建Abaqus作业。

该补片通过仅说明当前单元/材料在平直膜向状态允许正确法向收缩；不排除曲面背景约束、膜弯耦合、壳近似或真实几何差，也不认证20%及设计梯度。原所有来源与r30结果冻结。
