# r35：冻结状态的曲面穿厚度运动学诊断

依据唯一规划第3步及用户继续追查5%来源。仅复用r30/r34既有初始静态位移，不新求平衡/切线/AD/Abaqus，不改变原网格、材料、界面、η、厚度或边界，不继续添加积分层级。

运行前冻结原r33的1941单元与r32前20%面积中面选区。原27点用于相同位置、相同权重的两状态材料分区：φ<0.001、0.001–0.01、0.01–0.9、φ≥0.9。r34在共同27点下的后处理能量不冒充其自身混合积分平衡能量。储能份额分母为该状态、该共同规则下的同一1941单元总能，不能把两组百分比相减后命名为整体刚度贡献。距离分箱0/0.1/0.2/0.225/0.25/0.275/0.30/0.35mm与≥0.35尾部固定。

穿厚度剖面使用所有原固定主承载面片的质心及其原法向，z∈[-0.35,0.35]mm，等距81个观测点；这是已有Q2位移的点求值，不是新积分规则。按原面片面积加权，原质心选区不根据新状态更改，不筛掉最近面切换；记录实际周期最近面/距离/占据、最近面法向与固定线方向的变化。原Gauss的最近点位于边/角时，法向只是面片代理，切向距离比例>0.05单独报能量份额，不删样本。

由ε的局部切面部分定义平面应力理想法向应变εnn_ps=−ν/(1−ν)tr(εT)，比较实际εnn及其残差；剪切使用εnt向量。三维能量点态恒等分为切向平面应力能、法向残差能与横向剪切能。这个分解不具全局变形兼容性，不能当因果修正或直接改本构；壳E33/横向剪切未请求的输出不冒充真实法向收缩/剪切参照。量化法向应变的加权最小二乘比例与RMS残差，避免逐点除以可能过零的局部预测。应变以宏观a=1e−4说明量级；实际应力含φ缩放，单位实体材料应力另报，避免软域低应力掩盖畸变。线剖面按原面积权重，不能当体积能积分。

总预算900秒，点求值4096一批；超预算或预定检查失败停，不增加层级/状态。原r30全域/选区储能重现≤1e−10、r32法向/剪切能重现≤1e−10、两状态点态能恒等≤1e−10、输出有限且预算满足。以上仅数据/实现检查，不设必须找到主因的结果门槛。所有原科学源/结果在运行前后核对SHA256。
