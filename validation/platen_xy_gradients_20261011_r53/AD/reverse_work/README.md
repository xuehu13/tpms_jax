# G5%完整加载功反向回传：通过

从零沿原20%/4ms五次平滑加载的前缀推进到5%，共24,789步。加载功W=0.479909121914 N·mm；本次对W实际进行完整路径反向VJP，并与已通过双步长差分的厚度JVP核对。

| 项目 | 结果 |
|---|---:|
| 反向dW/dt | 1.258143623833 N |
| 正向dW/dt | 1.258143623830 N |
| 两者相对差 | 2.95×10⁻¹² |
| 重算前向与原路径的相对差 | 3.65×10⁻¹³ |
| 实际用时／冻结上限 | 90.89／120 min |

这次回传包含占据、共享材料内力、HRZ质量、XY宏观投影惯性、端部占据面积、初始状态、全部时间步及功积分。时间离散固定，不包含自适应减步或拒绝决策的导数。每256步保存主机检查点，块内分层重算，贯通完整显式动态路径。

同一次VJP还得到界面10–90%宽度w的加载功导数0.324624677509 N。**该值已计算，独立宽度差分尚待核对，不能由厚度通过推断宽度已验证。** 本次反向目标只有加载功；末端总力的厚度导数由第1步JVP/FD验证，没有宣称末端力VJP也已执行。

结果限于本次G构型、5%压缩、共同中面端部压板和XY周期的既定动态模型。它验证求导实现，尚未验证Abaqus或实物的同一参数敏感度，不能外推10%/12%、其他构型或形态梯度。原20%导数符号失败保留。
