## 方法、目标及完成条件

沿用G单胞L10mm、厚0.5mm、界面10–90%宽0.05mm；NH E10MPa/ν0.3/密度1e−9 tonne/mm³、η1e−4；N32 HEX27/27点、HRZ、objective_void/C²、共同中面端部压板、XY周期与自由横向伸缩。原共享材料、内力和前向科学结果不复制、不修改。

使用原20%/4ms五次加载的前缀，无保载。G固定dt约57.9993ns；5%共24,789步，约10%共34,483步，约12%共38,189步。总导数包含占据、内力、HRZ质量、XY宏观惯性、端部面积和全部时间推进，不对自适应接受/拒绝或步数取整求导。延伸时复用各自独立前缀的状态、累计功及完整参数切向；这仍是从零开始的总导数，不是固定末态偏导。

主目标加载功W=∫F_top dδ，单位N·mm；对t或w的导数单位N，末端力导数单位N/mm。明显非零导数的AD/FD差及两档FD差均按冻结1%门槛，近零用冻结的无量纲绝对口径。界面宽度属于数值几何近似参数，不能用来拟合壳或冒充实体壁厚。

实际F/J不夹断，主要材料φ≥0.01要求实际J>0，全部虚域J和能量保留。G约12%五条路径主要材料J采样最小约0.7462；低占据虚域存在翻转，按原客观续接模型保留。有限采样不等于每时每点的严格证明。
