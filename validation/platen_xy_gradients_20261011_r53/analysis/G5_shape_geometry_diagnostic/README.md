# 最近三角面距离：小邻域单侧斜率诊断

本诊断只重新查询实际移动的三角曲面，不推进动力学，也不改变验收门槛。原完整路径仍为功通过、末端力未通过。

| 形态扰动h | 占据刚度字段中心FD/JVP相对L2差 | 左右单侧斜率差（相同归一化） |
|---:|---:|---:|
| 1e−6 | 0.0885265% | 0.178412% |
| 1e−7 | 0.000114505% | 0.00150595% |
| 1e−8 | 0.000114516% | 0.000273155% |

较大扰动会跨过窄的最近三角面切换区；在更小邻域，单侧斜率明显接近解析最近距离导数。最近面编号变化数量仍较多，不能仅凭编号变化判定不可微。极小扰动也会受几何求交浮点分辨能力影响，因此不据此无限缩小步长。

随后在既有完整保存态及其完整切向上做局部数值分辨检查：h=1e−7/5e−8的反力观测FD与解析导数差约0.02515%/0.01091%。该检查人为使用线性化状态，**不是完整响应梯度验证**；它仅支持启动一次有界的实际全路径FD诊断。

完整数值及误差最大的30个查询点见metrics.json、convergence.csv、largest_query_errors.csv。距离为单胞归一化单位，a为无量纲，字段为无量纲刚度比例。新完整差分仍须使用真实曲面、从零推进并满足原1%与差分减半门槛。
