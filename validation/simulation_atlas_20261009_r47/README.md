## T的影响：已有记录已经说明什么

| 构型 | T (ms) | 已保存加载最大力位置 (%) | 最大压缩力 (N) |

diverse_04同壳模型由40ms加快到1ms，记录最大力位置由11.4161%移到12.7867%，相差1.3707个百分点，最大力增约7.85%。0.25ms时整条曲线已经明显变化，5.4701%的加载最大值不宜与较慢曲线的跳跃事件直接等同。各原能量、惯性、人工能失败指标没有改判。diverse_28已有20/40ms壳峰位仅差0.0410个百分点，峰力仅差约0.0128%，说明本次所见T敏感性依构型和时长区间而变。

T是20%幅值smoothstep的物理加载时长，**不是计算耗时或显式稳定时间步dt**。相同时间函数形状缩短T会增大规定速度、加速度；当前NH实体本构没有引入材料应变率依赖，T仍能通过动力推进、变形历史和Abaqus原有体积粘性等改变响应。不能把不同T下的N32/N64直接排成网格精度次序。Standard的步内时间可重置，仅是伪时间，没有与Explicit同义的T。

同T也仍有差异：二值N32 T4ms的记录峰为15.2387%，匹配壳T4ms为11.8241%，相差3.4146个百分点。因此T是值得分离的因素，但已有数据不支持把所有差异都归给T。二值N64 T1ms仍只有13.5877%的增载末点，没有捕获峰，不用它的末端最大值计算峰位误差。

## 条件与指标怎样读

共同薄壁对象为原周期中面，单胞边长L=10mm，通常厚度t=0.5mm，E=10MPa、ν=0.3，实体密度10⁻⁹ tonne/mm³。当前XYZ周期波动、横向宏观应变0。早期平端诊断、厚度扰动、填料嵌入和资源探针均单独标注；不混同当前生产条件。JAX常规没有额外阻尼、接触、塑性或质量缩放；Abaqus Explicit保留原默认体积粘性。壳填料还包含嵌入耦合、重叠填域与额外质量，不能叫作JAX C²模型的等价实现。

N表示单胞每方向背景单元数。HEX8/HEX27分别是8/27节点六面体；“27点”是3×3×3高斯积分，与27节点是两个概念。64点是4×4×4积分。w表示占据界面的10–90%过渡宽度，单位mm，不是壁厚；二值为实际参考高斯点上硬阈值，不是单元中心删空单元。η=10⁻⁴是数值软域模量/质量比例，C²是低占据能量延拓核，实际F/J没有夹断。局部12³指选定单元的1728点积分，外部仍27点，不是整个域的积分收敛证明。

- 压缩量=轴向缩短/L，图中以百分比表示；反力取压缩为正，保留真实负向振荡，不取绝对值修饰曲线。原接受记录之间只画折线，没有平移峰、拟合、平滑或外推。
- 加载曲线在各自T截断。保载另以时间画图；相对横轴(time−T)/T方便浏览，但各T对应的实际保载时间不同。
- 记录最大值与已观察峰分开：必须是窗口内部、已有后续降载才标“观察到峰”。这仍是动力路径指标，不是静态临界屈曲点或后续全局最大值认证。
- 曲线RMS是共同压缩窗口中2001个均匀点上的反力差均方根，先给N，再给除以参考**完整加载最大力**的比值。保留旧固定2.258914232N分母，不能混用这两种百分比。
- 功=10mm×∫F da，单位N·mm，在各曲线原节点加窗口边界插值后积分。相对功差=(本功/参考功−1)。没有用功差代替曲线差。
- 定点误差=(本力/参考力−1)，参考力接近零时会很大。另有绝对N差和除参考最大力的差。r15稀疏日志和局部重放只列原记录点，未计算假定全历史的RMS。
- 末端最大值没有峰后证据时，峰误差记n.a.；未覆盖15%或20%的窗口不填0、不补算。保载均值用时间积分，不用偶然接近的末端力代表保载。
- 初始K单位N/mm，宏观0.01%对应0.001mm位移，无惯性。早期1/5/10%只是独立平衡点，图中不补出不存在的JAX静力路径。
- 新表为统一回顾口径，包含“壳T对照”“JAX同核T对照”“积分/支撑诊断差”等。看参考ID、同T/同厚度和范围说明后再读误差。原门槛、失败、较早不同分母结果均不被新表覆盖。
