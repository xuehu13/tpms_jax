# r30：diverse_04 当前 N32 无惯性初始切线

目的：把当前初始增载偏硬与加载速度/惯性分开，不认证20%路径或设计梯度。

冻结：原diverse_04中面，L10 mm、厚0.5 mm，E10 MPa、ν0.3，HEX27 N32、每单元27高斯点、η=1e-4、界面10–90宽0.05 mm、objective_void共享核、XYZ周期波动及宏观横向应变0。占据复用r15真实积分点数组，不重新近似几何。旧程序和证据字节保持。

背景侧：在F=I取共享材料核的精确初始切线，施加宏观εzz=-1e-4（0.01%压缩，对应0.001 mm），只求线性平衡。紧凑矩阵自由算子必须先对照共享核本构切线（绝对误差<1e-11）及全网格残差JVP（相对误差<5e-10）。JVP为状态切线，不是设计AD。求解在均值零空间去除三刚体平移，结束恢复原固定周期类；该平移规范与原固定节点静态问题等价。质量、阻尼、加载时长不进入方程。

求解最多6000次PCG，求解段最多900秒；不追加迭代或自动换求解器。停止目标递推残差1e-10，验收使用真实自由残差≤1e-8初始右端范数；能量与宏观功相对差≤1e-6，周期波动差≤1e-12归一化长度，所有值有限，最大应变≤0.02且全部采样J>0.98。失败保留结果并不称静态通过。

壳侧：复用r15原S3R节点、单元、0.5 mm五截面点和全部平动/转动周期方程及固定节点；新Abaqus/Standard线性小变形一步，无接触/塑性。E10、ν0.3的线弹性是原NH在F=I的精确初始切线，不作为20%替代材料。原动态输入保持，另建新作业，最长900秒；无自动重试。输出U/UR/RF、ALLSE/ALLAE/ALLWK。验收位移0.001 mm，能量（含人工能）与半功差≤1e-5，人工能≤1%外功，周期方程另核对。

主比较：K0=|Fz|/(0.001 mm)，差值=(K背景/K壳−1)，分母提前固定为本次同中面壳K0。10%仅已有范围性工作目标，不是物理认证。1–5%旧动态曲线供背景，不能与本次0.01%视为同一压缩量。

判读：静态偏硬保留则排除“惯性是初始偏差的唯一原因”，随后只研究几何材料权重/局部运动学中的一个因素；若接近则下一步只查一个动态因素。本实验不改变E/t/η/界面，不跑长路径、不新建复杂体网格、不开展训练或形态AD。
