# r37：用户指定的界面陡峭度单因素诊断

启动前固定0.025/0.05/0.10mm的10–90%界面宽度；ℓ=width/(2ln9)，逆长度1/ℓ越大，过渡越陡。0.05原r30作为冻结基线，另外两档各独立从原r30解作为初始猜测，达到同一残差要求后才比较。L10/t0.5/E10/ν0.3/η1e−4、XYZ/宏观横向应变0及N32 HEX27/27点均不改。本初始算子无质量/阻尼，不是新的显式路径。

原距离数组不改，仅重新计算自身Gauss点φ；同共享材料在J=1的初始切线为原占据加权各向同性弹性，沿用r30已核对公式。每档最多6000迭代，总900秒，不追加失败迭代。残差≤1e−8、功恒等式≤1e−6、PBC≤1e−12、初始小应变范围必须通过。

每个有效状态仅在原1941冻结单元以既有8/12规则复积分，各自固定自身位移、宽度和分母。两级能量/材料体积差≤1%为局部稳定关口；27点与密积分差单独报，不称新全局K。选区外未密积分，不能认证全域积分或锐界面物理收敛。预定1%相对原K为诊断相关性量级，不按最接近壳挑参数，不修改生产宽度。

连续过渡可能改变有效材料表示，也可能改变欠解析采样，两者必须区分；宽度变动导致体积自然变化，不通过厚度修正补回。无新Abaqus/大压缩/设计AD。
