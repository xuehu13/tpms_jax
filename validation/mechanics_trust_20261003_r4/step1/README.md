这支持下一步检验薄壁Gyroid和另一构型。它并未证明整个TPMS族、局部应力或大压缩都准确；贴体参考仍是有误差的数值近似。

## 2. 锁定的比较定义

| 项目 | 本轮采用的定义 | 为什么要明确 |
| --- | --- | --- |
| 目标实体 | 三角函数Gyroid隐式场G，满足`|G|≤c`的片状实体 | c是函数值带宽，不是恒定毫米壁厚；不与旧恒厚壳强行等同 |
| 尺寸与基材 | 单胞边长L=1，基材杨氏模量Es=10，泊松比ν=0.3 | 一致单位的数值基准，尚未指定实际材料单位 |
| 加载 | 顶面轴向位移−0.01，底面轴向位移0，即名义压缩1% | 维护模型为小应变线弹性；百分比是加载尺度，不是非线性验证 |
| 周期与加载面 | 仅X/Y方向周期，顶底轴向位移保持平整，加载面的局部横向运动自由 | 不是完整XYZ周期均匀化，也不是带摩擦压板的多胞试样 |
| fixed | 宏观横向正应变为0；宏观剪应变保持0 | 限制整体横向膨胀，不是把所有侧面节点横向锁死 |
| relaxed_free | 松弛两个宏观横向正应变，使平均σxx、σyy为0；宏观剪应变仍保持0 | 不等于有限试件侧面自由，也没有松弛全部剪应力 |
| 背景近似 | 规则HEX8、八个实际Gauss点；在这些点求解析G再投影；β=40；孔隙/基材模量比η=10^-4；模量线性插值 | 连续占据和虚拟孔隙是数值几何近似，不是异质材料 |
| 独立参考 | 同一c的二值实体、C3D10二次四面体；孔隙没有单元；基材和宏观约束相同 | 独立检查背景近似对实体整体响应的影响 |

两边针对同一个目标物理问题，**使用不同的离散与几何近似**：背景保留过渡带和软孔隙，参考也用有限分辨率边界逼近解析曲面。因此这不是“完全同一离散模型”的比较，也不能把Abaqus结果当无误差真值。

主要输出统一为表观轴向模量`Eapp=2U/(Vgross·εz²)`；同时保留反力Fz、能量U和结构刚度`k=|Fz|/|uz|`。Vgross是包括孔隙的整个单胞体积，εz=uz/L。由于当前L=截面面积=Vgross=1，历史K、Eapp和k数值相同；换尺寸后须区分。参考反力法与能量法相互核对，不用实体平均应力替代总体积归一化的应力。ODB位移存储有微小浮点舍入，对表中所示位数没有影响。

## 4. 参考网格质量：支持证据与保留限制

基准c=0.541062已有两类独立敏感性结果，直接复用：

| 已有检查 | fixed整体模量变化 | relaxed_free整体模量变化 | 能回答什么 |
| --- | ---: | ---: | --- |
| G24同一实体边界，有限元R0→R1加密 | 0.2933% | 0.2722% | 同一边界下位移离散变化较小 |
| G24保持边界/连接，改善内部节点质量 | 0.00653% | 0.00525% | 该质量改善没有显著改变整体刚度 |

G48基准仍有28,635个畸变警告单元，占数量7.371%；它们只占实体体积约0.970%，占应变能约1.173%（fixed）或1.234%（relaxed）。最差一小组单元的能量更低。例如平均比质量指标低于0.1的单元，占数量约2.373%，占能量约0.0384%或0.0428%。该指标描述单元形状，越接近1通常越规则；这里的阈值只是诊断分组。

这些记录说明，“7.37%的单元有警告”不等于“7.37%的实体体积或刚度都受到同样影响”。**但能量占比也不是误差占比，不能由此推断误差小于某个百分比。**很小的正Jacobian和形状差仍保留，局部应力最大值尤其不应作为认证输出。

限制必须随结果保留：质量改善和同边界加密做在G24，并非G48直接修复后的误差界；c=0.48和0.60也没有各自的同边界有限元加密/质量改善对照。两锚点的参考加密变化、输入检查及拓扑为整体响应提供支持，不能将基准的质量结果直接认证为所有几何的误差保证。外存求解警告主要影响计算成本，不能与几何质量警告混为一谈。

据此，现有参考的定位是**指定小变形整体响应的工作参考**。当前没有一个必须再算基准才能回答的明确缺口；若第2步薄壁/新构型出现差异，将针对其自身参考作检查，不能沿用这里的质量敏感性。
