# TPMS 研究阅读入口

**先读 [综合报告：方法依据、已有证据与可信范围](TPMS_RESEARCH_REVIEW.md)。** 面向首次了解项目的读者，解释材料占据、背景网格、积分点、主要数字、小/大变形和逆设计关系。可分享版本为 [PDF](output/pdf/TPMS_RESEARCH_REVIEW.pdf)。

继续工作仍按 [研究背景](RESEARCH_BACKGROUND.md) → [唯一近期主规划](RESEARCH_PLAN.md) → [当前状态](PROJECT_OVERVIEW.md) → [文件地图](FILE_MAP.md) 阅读。当前计算可信性优先，训练暂缓。前三轮收口；第四轮[第1步](ROUND4_STEP1_REPORT.md)参考审计完成，[第2步](ROUND4_STEP2_REPORT.md)记录Primitive通过和薄壁参考未成立，[第3步](ROUND4_STEP3_REPORT.md)完整均匀实体有限应变基准通过至20%；下一步是已验证Gyroid的有限应变探查，尚未启动。均匀体通过不等于TPMS大压缩通过。综合报告是制定第四轮前的阶段总结快照，原数值结论不变，后续执行状态以主规划为准。

[文献记录](PAPER_ROUTE.md)；冻结报告：[第一轮](NEAR_TERM_REPORT.md)、[第二轮](ROUND2_REPORT.md)、[第三轮](ROUND3_REPORT.md)。旧阅读副本见 [历史索引](history/reading_copies_before_review/README.md)，不作执行入口。正式程序在WSL，Windows work/tpms_jax为历史传输副本。
