## 1. 这一步回答了什么

这一步检验：把第3步已验证的有限应变材料放入已认证的中等壁厚Gyroid背景模型后，能否得到可信、可负担的压缩路径，为后续学习与逆设计建立计算基础。

N16和N32预检查均完成至5%压缩，保存状态的平衡、周期约束、正局部体积比和能量检查通过。N48完成0.01%的小应变点；其割线刚度与冻结的同参数线弹性结果相差约0.00171%。随后在0.5%点触及预先锁定的每点300秒上限，监测程序停止了该路径。

因此，本轮获得了**非均匀Gyroid有限应变前向实现的内部一致性及实测成本证据**。N48/N64精度检查尚未完成，独立贴体有限应变参考也没有启动，不能给出“TPMS已经准确算到5%”的结论。当前首先暴露的是PETSc GMRES/GAMG配置的求解成本；已完成状态没有触及非正体积比、严重孔隙压瘪或不平衡停止项。未完成加载点仍未知。

第4步按原计划允许的资源停止条件收口，未强行推进10%/20%，也没有换c、提高孔隙刚度或放宽精度门槛。训练和逆设计继续后置。

## 2. 固定的几何、材料和加载

| 项目 | 本次定义 | 含义 |
| --- | --- | --- |
| 几何 | 基准Gyroid，`|G(X)|≤c`，c=0.541062，单胞边长L=1 | 已有小变形证据的中等壁厚对象；c是隐式函数带宽，不是恒定毫米壳厚 |
| 背景 | 规则全积分HEX8；每单元8个实际Gauss点 | N是每轴单元数；不是输入数组分辨率M |
| 占据场 | `ρ(X)=sigmoid[β(G+c)]−sigmoid[β(G−c)]`，β=40 | ρ在0与1之间表示光滑几何占据；不是异质材料设计 |
| 孔隙比例 | η=10^-4 | 零占据位置的初始模量为基材的万分之一 |
| 基材 | 第3步匹配的可压缩Neo-Hookean，初始E0=10、ν0=0.3 | 算法基准，未标定真实金属或聚合物 |
| 加载 | XY周期，宏观横向应变固定；底部z位移0、顶部−a | a是压缩位移除以初始高度；端面横向运动仍允许 |
| 参考 | 锁定原G32/G48二值C3D10网格和实际INP的指纹 | 准备在新目录换为同一超弹性材料与加载；本次未生成或提交新参考作业 |

插值的是每单位初始体积的应变能：

`W_bg(X,F)=[η+(1−η)ρ(X)] · W_s(F)`

`W_s(F)=μ0/2·[J^(−2/3)tr(FᵀF)−3]+κ0/2·(J−1)²`

μ0=E0/[2(1+ν0)]、κ0=E0/[3(1−2ν0)]；F是变形梯度，J=det(F)是局部当前体积与初始体积之比。J=1表示局部体积不变，J=0.73表示缩为原体积的73%；它不同于整个单胞的轴向压缩百分比。J必须大于0。

ρ保持在**初始材料坐标X**的Gauss点上。变形后材料随位移移动，不重新用当前坐标计算占据程度。这样避免在加载中改变几何定义或用占据变化隐藏畸变。两项材料常数、应力和切线均随同一个正权重缩放，因此零应变切线恢复此前的线性模量插值；新增材料点检查对此作了独立核对。

运动学沿用`u(X)=H·X+w(X)`、`F=I+H+∇w`、`H=diag(0,0,−a)`。w是求解出的周期非均匀位移。这次没有强迫整块TPMS作均匀仿射变形。应力为第一Piola应力`P=∂W_bg/∂F`，整体反力从未修改的弱形式节点内力提取；不把平均Cauchy应力套用均匀体换算来代替结构反力。

有限应变能量及自动材料导数沿用[JAX-FEM官方示例](https://deepmodeling.github.io/jax-fem/learn/hyperelasticity/example.html)。[Wang等的研究](https://orbit.dtu.dk/en/publications/interpolation-scheme-for-fictitious-domain-techniques-and-topolog/)讨论低刚度域大位移畸变及专门能量插值；本轮采用普通缩放超弹性能量，没有实现该稳定化方案。当前观察到的是成本限制，尚无证据据此要求先改孔隙本构。

## 3. 先锁定预算，再运行

原顺序保持为：N16/N32实现与资源预检查 → N48/N64精度网格及半步检查 → G32/G48独立实体对照 → 条件成立才扩展10%和20%。粗网格预检查不能替代精度网格。

基础路径保存零状态、0.01%小应变点，然后以0.5个百分点增量到5%。注意**0.01%、0.5%、5%**分别是a=0.0001、0.005、0.05，不能混写。N48的失败尝试是0.5%，并非5%。

每条JAX路径上限1800秒，每个加载状态上限300秒，最多15次Newton校正。主机RSS采样上限12.5GiB、设备总已用内存上限7.2GiB，并保留至少1.5GiB可用主机内存。原生PETSc GMRES/GAMG求解稀疏方程，JAX在RTX 4060 Laptop GPU上计算局部材料/单元导数；它不是整个求解都在GPU上运行。

预算允许最多两条预检查、一项失败半步诊断、三条精度路径和两条条件扩展路径；Abaqus最多5项分析和5项datacheck。实际只尝试3条JAX路径，半步诊断0、Abaqus分析0、datacheck0、设计梯度0、训练0。完整维护测试与科研路径分别计数。

物理检查包括缩减残差≤10^-8、反力平衡/反力与平均第一Piola口径一致、周期及端面位移误差≤10^-10、J>0，并预先以低占据区最小J<0.1作为严重压瘪停止信号。该0.1是本轮诊断门槛，不是接触判据或行业标准。

计划中的独立曲线工作目标为最大力差/参考最大力≤5%，目标网格与步长变化约≤1%，同时核查变形模式、参考质量和能量。当前没有通过这些外部精度检查，也没有改动门槛。

N16/N32的全路径最大力差除以N32最大力约为**5.268%**，储能同口径差约5.124%。这是粗网格离散变化指示量，不是相对真实解的误差。它说明需要继续目标网格检查，不能凭N16便宜、N32能跑通就认证精度。

N48在0.01%点的割线刚度为1.9838093，冻结同参数线弹性刚度为1.9837753，相差约**0.001712%**。很小非零应变下允许有有限应变修正；这个结果支持新增实现正确接回线弹性极限。它不是0～5%精度认证。

## 5. 为什么停在这里

N32除小应变点外，每个完成状态约68～107秒；对应Newton计时表中线性方程部分约占92.9%～95.5%。材料和单元局部导数并非主要耗时来源。

部分N32路径与CPU维护检查重叠，计时不是标准性能测试。N48启动时维护检查已结束；其预算停止为独立的实测记录。

N48小应变点完成耗时约297.83秒，两次Newton校正的线性部分合计约280.59秒。0.5%点的第一次线性校正约210.38秒，残差从约1.71×10^-3降到6.12×10^-6；第二次校正期间触及300秒门槛，监测程序终止进程。该点尚未达到平衡验收，不能采用其试探状态。

**停止类型是每点时间预算，未触发内存上限。** N48主机RSS采样峰值约5.53GiB，已完成点的进程历史峰值记录约5.97GiB；两者不同是采样可能遗漏短暂峰值。设备总已用内存采样峰值约2.57GiB，包含显示等其他使用，不当作纯FEM设备内存。N64的两点外推内存只是估计，没有实际运行证据。

这个结果限于当前机器、PETSc GMRES/GAMG配置和严格残差设置，不是“背景法或JAX-FEM理论上算不了”的证明。线性求解计时尚未拆分预条件器建立与Krylov迭代，所以进一步原因仍待有针对性的检查。单纯提高时限可能让单个案例继续，但其成本是否适合后续设计循环尚未建立。

本轮没有为时间瓶颈添加孔隙稳定化、接触、塑性或训练框架。独立参考、网格/步长检查、变形模式、失稳及自接触判断没有执行；均未被宣称通过。当前无法确定TPMS有限应变的物理可信上限，更不能将粗网格5%或均匀体20%外推至真实TPMS压溃。
