# Abaqus 2026 均匀实体基准结果（2026-10-01）

三种工况均实际求解成功，错误和警告均为 0，结果验收全部通过。
用户运行横向固定工况；agent 使用命令依次完成其余两种松弛工况的数据检查、
求解及 ODB 结果提取。所有模型为单位立方体、E=10、ν=0.3、εz=-0.01，
XY 周期、上下平面轴向加载，64 个 C3D8 单元，512 个积分点。

| 工况 | εx=εy | 轴向反力 Fz | 总应变能 ALLSE | 验收 |
| --- | ---: | ---: | ---: | --- |
| 横向固定 | 约 0 | -0.1346153915 | 0.0006730768946 | 12/12 通过 |
| 给定解析横向应变 | +0.003000000026 | -0.1000000015 | 0.0005000000237 | 13/13 通过 |
| 自动横向松弛 | +0.003000000026 | -0.1000000015 | 0.0005000000237 | 13/13 通过 |

反力最大相对理论误差约 5.11e-8，能量最大相对误差约 4.75e-8，均低于 1e-6
验收目标。松弛工况横向平均应力约 1e-17，全部物理节点最大仿射位移误差
约 2.24e-10。给定与自动松弛工况的反力、能量和宏观位移在当前 ODB 输出
精度下相同。

这些结果验证了均匀材料下的周期约束、加载、自动横向松弛和提取流程。
下一层非均匀积分点材料场仍需核查 C3D8 的选择性体积积分与 JAX HEX8 的
区别；本结果不能替代该单元公式对照，也不能证明二值 Gyroid 几何已验证。

`summary.csv` 汇总三种工况；各 `.acceptance.json` 含完整验收指标；
各 `.sta` 记录求解成功状态；`run_manifest.json` 保存输入、ODB 和报告的
SHA256 指纹，便于复核。ODB 和完整 `.dat/.msg` 保留在用户的 Windows
作业目录，本包未包含大型 ODB。
