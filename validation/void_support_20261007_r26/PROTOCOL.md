# r26：独立JAX低占据支撑能量诊断（启动前协议）

只研究diverse_04观察降载峰错位。几何、10mm单胞/0.5mm壁厚、NH E10MPa/ν0.3、η1e−4、0.05mm界面、XYZ周期/宏观横向应变0、HEX27 N32/27点、HRZ质量、无阻尼/接触/塑性全部保持。原正式程序字节和旧结果保持；仅本目录诊断适配器复用正式显式入口。

唯一材料因素：W_diag(F,φ)=s(φ)W_original(F,φ)，s=.1+.9g(φ)，g为原C²门控（φ≤.001为0，φ≥.01为1）。真实NH域φ≥.01不变；低占据区能量、P=∂W/∂F及切线同源降低，不能仅改观测反力。过渡域并非全为十分之一。η、占据、参考材料坐标、虚域J截点及实际F/J不变。质量独立使用原占据与η，完全不乘s。该项不是修改物理材料、也不是推荐正式参数。

从零单次推进，复用r18中央差分、步长上界、安全系数.8、初始步长/16下限、128/16块、回退/拒绝及真实NH正J/有限性保护；不做短重放拼接。原20%目标的0.004s五次加载时程不变，只将诊断停止时刻设为该原时程17%对应时刻（约0.00284033s），无保载。初始名义步长仍按原0.0044s总长度计算，避免改变积分设置。允许动态跳跃：原高KE持续时长仅记录，不作为本次停止项；原准静态失败不被改写。适配器只有停止时刻/旧准静态停止项两处受检替换，原推进、所有数值保护原样复用。

比较：冻结r18原JAX路径（到17.5363%）和r20同速率壳路径。主窗口1%–17%，峰区10%–17%，早期辅助窗口1%–8%。仅计算实际共同覆盖部分，完整窗口指标缺失时明确标记；不外推、平移或平滑曲线。报告动态宏观力与内部宏观力、观察峰位置/峰力、曲线RMS、压缩功、U/KE、实际J和虚域翻转/拒绝、步长。RMS同时用原固定2.25891N和匹配壳观察峰5.229988098144531N作分母；峰力自身以匹配壳峰作分母。

启动前诊断判读规则：完整覆盖10%–17%，峰后至少0.5个百分点且反力下降≥10%才能把样本峰称观察降载峰；若与原JAX峰位置移动≥0.5个百分点，或1%–17%曲线RMS变化超过匹配壳峰的2%，记为可见敏感性（诊断阈值，不是物理精度认证）。有效覆盖且低于这两阈值才降低低占据支撑优先级，不排除整个连续界面表示。提前非有限/真实NH翻转/步长下限/预算停止且未覆盖主窗口，不作“不敏感”结论。改善贴壳不证明唯一原因或正式改进；适配控制步长可能随新切线变化，必须分报。

一次尝试主体预算1500s（沿用r18已知25min成本；约15min为通常参考而非硬限）；几何准备、JIT/主体、分析分别报告。预算从原控制入口计时，包含其首次切线/推进编译，不能冒称纯计算时间。失败不自动降低下限或追加重试。不新增全路径/形态AD、Abaqus作业、有限填充、VUEL、谱迭代或训练。局部同源导数检查只证明诊断实现一致，不认证设计梯度。
