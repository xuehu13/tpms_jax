# G压板研究 r51：当前结论与证据入口

更新2026-10-10。**G薄壁单胞在共同的中面端缘等效压板加载、XY周期与自由横向伸缩条件下，JAX背景实体和Abaqus壳的0–20%压缩响应较接近：全曲线RMS差3.42%、加载功差3.86%、末段保载均力差5.76%，达到本轮预先约定的三个约10%目标。** 这为背景实体法在该受控薄壁大压缩问题中的前向计算能力提供了积极证据。

比较的是共同“中面端缘接触”理想化。Abaqus壳厚仍用于截面计算，其节点型接触只感知中面端缘；JAX保留有厚度实体和连续占据，只归并端部接触权重。两端有厚度的外侧都可能越板；Abaqus实际越板量尚未测定。不能把当前壳参考视作完整有限厚度接触真值。

2%与20%的加载历时及RMS分母不同，表格用于区分实验，不作同条件误差排名。20%结论来自独立从零路径，没有把短程拼接成完整结果，没有调物理参数拟合曲线。

两端采用相近的端部接触理想化，单元运动学、罚律、接触插值和惯性离散仍不同。该结论限定于本次G构型与参数；完整有限厚度接触、自接触、跳跃峰位及该接触模型的设计总梯度尚未验证。 20%曲线持续增载，不验证跳跃峰位。原有限宽2%失败及旧XYZ周期迁移、设计梯度失败记录保持。
