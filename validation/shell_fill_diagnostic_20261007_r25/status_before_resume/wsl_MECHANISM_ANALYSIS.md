# 峰值差异：当前判断与解释边界

更新2026-10-07。当前暂停，本文只解释已有证据和候选原因；执行顺序只见[唯一规划](RESEARCH_PLAN.md)。r23完整同背景路线的旧说明已备份，r24的27节点源文件尚未编译/运行。

## 1. 为什么难分析

跳跃附近的局部折叠、人工软域、几何离散及动态触发可能相互影响。diverse_04同为10%压缩时两端力差约7%，同速率壳观察峰11.8241%、JAX15.9409%；后续错位放大曲线差。不同压缩位置各自峰力差35.23%，不等于整体模量错误35%。观察峰不是已认证静态临界点。

当前模型为10mm/0.5mm、NH E10MPa/ν0.3、XYZ周期/横向宏观应变0。JAX为HEX27背景位移、连续距离占据、HRZ及C²虚域；Abaqus为S3R壳，空隙为空。两者真实参数对应，但运动学、界面、质量和数值算法不同。壳也不是精确三维真值。

## 2. 按现有证据排序，不赋虚假概率

| 候选原因 | 当前判断 | 证据和限制 |
| --- | --- | --- |
| 薄壁局部折叠表示 | 较高优先级 | Q2三维位移跨界面/孔隙与壳转角不同；距离带/面片/平滑影响弯曲。旧HEX27改善过，但不能宣称锁定是唯一原因 |
| 软域额外支撑 | 适合优先低成本试验，尚非主因 | 小净力/储能不排除方向刚度影响；未收敛候选分项不是临界证明，大变形支撑也不只由η决定 |
| 分支触发与微小扰动 | 保留 | 两套离散自带不同扰动，尚未控制；壳实际跳跃增量不是特征模态，不能挑扰动校准 |
| 质量/耗散/参照质量 | 保留；纯速率优先级降低 | 壳10倍加速仅移峰0.4080个百分点；尚未排除质量和触发相互作用，快壳人工能量/漂移有原失败 |
| 单位/简单本构或反力实现差错 | 目前优先级较低，但未全部排除 | 旧同状态桥接与已有恢复核对支持部分实现；不认证当前完整独立路径 |

低刚度区大畸变是虚域文献已讨论的问题，能量处理可改善求值和稳定，不保证消除峰值差。[Wang等2014](https://doi.org/10.1016/j.cma.2014.03.021)。[Abaqus屈曲说明](https://docs.software.vt.edu/abaqusv2025/English/SIMACAEANLRefMap/simaanl-c-postbuckling.htm)讨论动态跳跃及初始缺陷；不据此宣布本项目已找到原因。

## 3. 旧填充模型与拟议试验各回答什么

早期独立线性HEX8材料场对照验证了1%离散方程。r6原生C3D8软背景指定全部JAX保存位移，内部力/储能差1.13%/1.08%；是同状态核对，不是独立0→20%路径，不是壳＋填料。输入/ODB在E盘`background_bridge_20261005`，正式证据在`validation/large_compression_20261005_r6/background_bridge`。

拟议壳＋普通实体软填充检验“附加支撑能否改变观察峰”，不追求完全复现JAX。嵌入会让壳平移服从背景插值；近零刚度也不删除约束，原周期方程需协调，重叠质量/刚度须记录。[嵌入官方说明](https://docs.software.vt.edu/abaqusv2025/English/SIMACAECSTRefMap/simacst-c-embeddedelement.htm)。因此先看同连接/质量的近零刚度对照是否已改变原壳；未通过便不能作填料刚度归因。

JAX低占据能量干预更接近现有模型的单因素诊断。两端影响一致支持软域参与，但不同有限变形填料不要求数值一致，也不能唯一归因。更严格的独立HEX27/C²/HRZ参考原本回答实现一致性，成本较高；现在暂停该开发。

## 4. 当前能下的结论

r17解决的是16%左右原数值失稳线索；r18只到17.5363%预算停；r20限制了速率解释；r21/r22没有定位真正临界方向。原记录见[阶段报告](CRITICAL_MODE_PROGRESS.md)。不能把这些过程拼成20%成功、静态认证或因果证明。

diverse_28已有有限20%前向范围，diverse_04仍未满足迁移目标；新核完整20%设计梯度未认证。适合继续有边界的原因研究，不承诺全面替代。现在暂停整理，不启动模型、训练或新的误差扫描。
