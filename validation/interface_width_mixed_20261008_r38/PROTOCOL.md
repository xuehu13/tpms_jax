# r38：陡峭度变化与积分欠解析分开检验

启动前冻结。r37原27点把界面宽度从0.05改0.025mm，K下降1.4872%，但固定场选区12级复积分新增能量达该状态全能的4.6774%，高于原宽度2.0874%。因此不能把对壳降至4.1304%直接当改进。

只做一个0.025mm初始静力确认，以已完成r34的0.05mm相同部分密积分作为对照：原1941单元12点每轴，其余27点；位移空间、厚度、材料、η、XYZ约束均固定。沿用原r34矩阵组装/算子；占据按新宽度同时进入所有原点及密积分点，不能只改选区。最初猜测取r37该宽度有效原27点解。不是后期加载，不引入质量/阻尼。

矩阵对称、常量平移零力、r37自身固定场密积分增量/总能重现后才求解。最多6000迭代、总900秒；真缩减残差1e−8、能量功1e−6、PBC1e−12及原Gauss小应变范围沿用。不追加失败迭代，不补新的积分等级，不挑最接近壳的参数。相对同规则r34比较宽度效应；相对自身原27点比较积分效应，两个分母不得混用。

选区外仍非密积分，得到的是该有限诊断积分下的效应，不是全域积分/锐界面收敛或真实二值实体认证。不修改生产0.05mm/27点，不新建Abaqus作业或完整AD。
